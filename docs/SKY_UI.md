# 별하늘·그리드·분위기 카드 — v0.6.0

2026-10-03

- Mastermind의 실제 `VisualizerCard.tsx`와 `global.css`를 참고했다. 황금각으로 분포한 구체/내부 구체, 원근 투영, 작은 별 스프라이트를 경량 Canvas 2D로 구현했다. React·WebGL·외부 리소스·오디오 처리 노드를 추가하지 않는다.
- 기존 최종 출력 analyser의 30–220 / 220–2200 / 2200–12000 Hz 대역 전력을 읽는다. attack 60 ms / release 320 ms로 완화해 각 점의 반경·밝기를 조절한다. 음량 슬라이더 뒤 신호이므로 실제 무음에 반응을 꾸며내지 않는다. idle 회전과 배경 별의 이동은 별도 장식이다.
- 280개 구체 점과 36개 배경 점. 기존 파형의 RAF를 공유하며 재생 20 fps, 정지 약 15 fps, DPR 최대 2. 숨긴 탭과 집중 화면에서는 별하늘 계산을 건너뛴다. reduced motion에서는 위치와 밝기가 정적이며 FFT를 읽지 않는다.
- 배경 그리드는 Mastermind 현재 구현의 60초/80px 속도로 오른쪽→왼쪽 이동한다. reduced motion에서는 CSS 애니메이션을 끈다.
- 분위기 카드 텍스트·아이콘 가운데 정렬. 레코드, 세 겹의 평행 곡선, 대칭 이퀄라이저로 교체했다. 설명 라벨은 추가하지 않았다.
- 낮은 데스크탑에서는 조절 슬라이더를 두 열로 배치해 별하늘과 악기 선택 공간을 확보한다. 모바일 별하늘은 플레이어 아래, 조절부 위에 배치한다.

## 검증

Chrome: 1440×900, 1366×768, 1280×720, 1024×600에서 스크롤·패널 겹침·가려진 버튼 없음. 768×1000, 390×844, 320×720에서 가로 넘침 없음. 각 카드 텍스트 중심 오차 1px 이하. 밝은/어두운 테마 렌더 확인.

배경 위치가 1초 동안 -2.40→-3.73px로 감소하는 것을 확인했다. 재생 중 별하늘 대역 반응 최대값은 [0.270, 0.057, 0.0034], 볼륨 0 후 2.5초에는 [0.0014, 0.00016, 0.000018]로 줄었다. reduced motion에서는 연속 캔버스 이미지가 동일했고 CSS animation은 none이었다. 집중 화면에서 별하늘 숨김, 재생 중 JS 오류 0. 합성·편곡·마스터링 코드는 변경하지 않았다.

## v0.6.1 — 확대된 눈송이와 강한 오디오 반응

원본 Mastermind와 재비교한 결과, v0.6.0은 base radius가 화면 높이의 .39배이고 변위 계수가 .18이라 구 전체가 보이는 상태였다. 원본은 .8배 반경에 bass breath .35, 스펙트럼 변위 .8/1.2와 별도의 80개 눈송이를 사용한다.

- 반경을 `max(width × .66, height × .95)`로 확대. 228×127px 카드에서 약 50→150px. 입자별 반경을 분산하여 일정한 구 껍질 윤곽을 없앤다.
- 오디오 반응은 원본처럼 dB 스케일 FFT 크기 ×1.5, bass breath .35, 외부/내부 변위 .8/1.2를 사용한다. 30–12000Hz 사이 50개 로그 구간을 사용해 파트마다 다른 변위를 만든다. attack 35ms / release 200ms.
- 300+100개 점과 독립된 눈송이 80개. 구체 입자는 최대 2.2 CSS px, 눈송이는 1–1.9px. 소리가 커져도 입자 크기를 키우지 않고 이동량과 확산 범위를 키운다.
- 재생 중 목표 갱신율 30fps. 실제 프레임 빈도는 브라우저 RAF와 스케줄링에 따른다. 정지·집중 화면·숨긴 탭·reduced motion 처리 유지.
- Chrome 기본 볼륨 55%에서 Warm desk / Quiet space / After hours 모두 확인. 공통 팽창 최대 1.36 / 1.33 / 1.42배에 주파수별 변위가 추가된다. 화면 내 입자 최소 153 / 163 / 150개. 무음 3초 후 반응값 <.00013, reduced motion 연속 이미지 동일, JS 오류 없음. 1024×600과 390×844에서 넘침 없음. 정지/재생 스크린샷에서 완전한 구의 외곽 대신 확대된 입자장을 확인했다.

## v0.6.2 — 원본의 3D 궤도 복원과 배경 이동 검증

v0.6.1의 눈송이는 2D 화면 좌표를 반복 이동했고, 깊이는 크기/밝기에만 쓰였다. 구체 점도 반경을 무작위로 분산했으며, 반경 변위를 적용하기 전의 z로 원근을 계산했다. 따라서 원본의 함께 회전하는 공간과 앞뒤로 지나가는 눈송이를 재현하지 못했다.

- Mastermind 실제 `VisualizerCard.tsx`의 황금각 배치, Y/X 회전, 반경 적용 후 원근 투영, camera/fov 1000, near clip 100, 80개 눈송이의 3D 공전/수직 진동을 이식했다. 원본의 30fps 증가량은 경과 시간 기준으로 환산한다.
- 원본의 저역 첫 10 bins 평균과 선형 50 bins ×1.5, 반경 .45/.8/1.2, additive blend와 부드러운 64px 스프라이트를 사용한다. 날카로운 중심점과 고정 최대 크기 제한을 제거해 원근에 따른 크기 차이가 보존된다.
- 작은 카드에서도 깊이가 유지되도록 가상 높이 320, 반경 256, 화면 확대 1.6배로 투영한다. 스프라이트 배율은 .8로 줄이며 실제 빛 영역은 스프라이트 중앙 절반이다. 이 화면 크기/입자 배율은 WORKSONG용 조정이다.
- 정지 상태에는 원본의 장식용 호흡을 복원하되, 진단의 측정 대역값은 0으로 유지한다. 재생 중 볼륨 0이면 장식용 신호로 대체하지 않는다. reduced motion에서는 모든 이동과 반응을 멈춘다.
- body 배경 페인트 대신 고정 pseudo-element를 transform으로 이동한다. 80px/24초로 우→좌 이동, reduced motion 준수. 사용자 앱 내 브라우저에는 초기 번들 `index-27LMfUHh.js`와 animation none이 남아 있음을 별도로 확인했다. 모든 브라우저의 정지 원인이 캐시라고 단정하지 않는다.

검증: Chrome 1366×768에서 3초 간격 스크린샷의 실제 배경선이 x=79–80에서 x=69로 왼쪽 이동했다. 세 분위기 재생 중 저역 반응 최대 1.01–1.14, 회전 진행, 눈송이 화면 진입/이탈 확인. 무음 반응 0, reduced motion의 연속 캔버스 동일, JS 오류 0. 1440×900 / 1366×768 / 1280×720 / 1024×600 데스크탑 넘침 없음, 390×844 모바일 가로 넘침 없음. 원근 크기비·근접 클리핑·공전 앞뒤 전환 회귀 테스트 추가. 음악 생성/합성/마스터링 코드는 변경하지 않았다.

## v0.6.3 — 여백 없는 분위기 선택

분위기 제목과 내부 카드 여백을 제거했다. 바깥 패널을 동일 크기의 버튼 3개로 채우고 칸 사이에 구분선만 둔다. 폭 900px 초과에서는 세로, 그 이하에서는 가로 3칸이다. 선택 표시와 키보드 포커스는 유지한다. Chrome 1366 / 1024 / 768 / 390 / 320px에서 외곽 여백·칸 간격 0, 동일 크기, 버튼 가장자리 클릭, 넘침 없음을 확인했다.

## v0.7.1 — 더 빠른 그리드

사용자가 24초 주기도 느리다고 요청했다. 재확인한 Mastermind 현재 웹 배포본과 로컬 소스는 80px/60초지만, 승인된 디자인 가이드의 `layout-and-panels.md` 예제는 80px/7.5초다. 이 차이를 설명하고, 더 빠른 움직임을 원하는 요청에 맞춰 가이드의 7.5초를 적용했다(이전 WORKSONG 대비 3.2배). 현재 Mastermind 웹 배포본과 동일한 속도라고 주장하지 않는다. 방향·간격·transform 레이어·reduced motion은 유지한다.
