# 드롭 제스처 v29 · D&B 하프타임 빌드와 드롭 직전 정적 · v0.35.0 / 생성기 v29

D&B다운 순간을 드롭(브레이크다운 뒤 리턴으로 들어가는 지점) 둘레에 넣는다. 로파이의 테이프 스톱(v24), 딥하우스의 리버스 심벌(v25)과 같은 성격의 단계다. 시드로 정해지고, 드물게 나오고, 매번 같은 자리에서만 나온다.

## 1. 진단 (v28)

D&B 브레이크다운은 모든 시드에서 같은 모양이다.

- **앞 4마디:** 드럼이 없다.
- **다음 3마디:** 하이햇 두 개만 친다.
- **마지막 마디:** 필인이 나온다. 대개 4박의 스네어 롤이나 톰이다. 필인이 없는 시드도 있다.
- **드롭:** 리턴 첫 마디에서 브레이크와 크래시가 한꺼번에 들어온다.

빌드가 비어 있어 드롭을 향해 쌓이는 힘이 약했다. 필인은 드롭 바로 앞까지 이어져서 드롭이 "숨을 멈췄다가" 터지는 맛도 없었다.

## 2. 규칙 (`src/drop-v29.ts`, `src/music.ts`)

### 하프타임 빌드

- **자리:** 드롭 앞, 하이햇만 남은 빌드 마디(필인이 없는 마디) 가운데 마지막 세 마디.
- **리듬:** 1박에 킥, 3박에 스네어. 2·4박에 스네어를 치는 D&B 브레이크의 반 속도라서, 드롭에서 원래 속도의 브레이크가 두 배로 빨라지듯 들어온다.
- **음색과 크기:** 같은 곡의 리턴 킥·스네어를 그대로 쓴다. 크기는 리턴의 62% → 74% → 86%로 마디마다 커진다.
- **빈도:** 연속된 폼에서는 하나 걸러 한 번이다. 그중 85%에서 나온다. 에너지 35 미만인 곡에는 넣지 않는다.

### 드롭 직전 정적

- **자리:** 드롭 바로 앞 마디의 4박(170 BPM에서 0.35초).
- **필인:** 4박에 있던 필인을 3박으로 한 박 당긴다. 원래 3박에 있던 드럼은 필인에 자리를 내준다. 필인 → 한 박 정적 → 드롭 순서가 된다.
- **울리던 음:** 정적 안에서는 아무것도 새로 시작하지 않는다. 그 전부터 울리던 패드·베이스·아르페지오는 정적 경계에서 끊는다. 화음·멜로디·아르페지오는 꼬리도 0.06초로 줄인다. 리버브·딜레이 꼬리만 남는다.
- **빈도:** 폼마다 시드로 55% 확률을 뽑고, 앞 폼에서 정적이 나왔으면 건너뛴다. 에너지 25 미만인 곡에는 넣지 않는다.

두 제스처는 따로 정해진다. 둘이 함께 나오는 폼에서는 "하프타임 빌드 → 필인 → 정적 → 드롭"이 된다.

## 3. 결과

- **빈도:** 8개 시드, 드롭 160번 가운데 하프타임 64번(40%), 정적 46번(29%)이다. 정적은 두 폼 연속으로 나오지 않는다.
- **렌더:** AB12CD 19–25마디(하프타임과 정적이 모두 나오는 폼)를 렌더해 구간 음량을 쟀다.

| 구간 | v28 | v29 |
| --- | --- | --- |
| 빌드 20–22마디 | -15.2dB | -14.6dB |
| 23마디 1–3박 | -14.3dB | -13.1dB |
| 23마디 4박 | -30.8dB | -41.1dB |
| 드롭 24마디 | -12.1dB | -12.1dB |

- **정적:** 4박이 리버브 꼬리만 남아 드롭보다 29dB 작다(v28은 19dB).
- **필인:** 3박으로 옮겨 와서 3박 음량이 1.2dB 커졌다.
- **드롭:** 드롭 마디는 v28과 한 음도 다르지 않다.

## 4. 검증

- **`tests/drop-v29.test.ts`:**
  - 로파이·앰비언트·딥하우스 악보가 v28과 같다. D&B도 하프타임·정적 마디 밖은 v28과 같다.
  - 하프타임 마디에는 1박 킥과 3박 스네어만 더해진다. 드롭보다 작고, 마디마다 커진다. 드럼이 빠진 마디에는 나오지 않는다.
  - 정적 마디: 4박에 시작하는 음이 없다. 드럼 밖의 음은 4박 전에 끝난다. 필인은 정확히 한 박 앞으로 옮겨진다. 드롭 마디는 바뀌지 않는다.
  - 빈도: 정적 25–60%, 하프타임 30–60%이고, 정적은 연속으로 나오지 않는다. 에너지가 낮으면 둘 다 나오지 않는다.
- **기존 테스트:** v28 테스트의 기본 버전 확인을 "28 이상"으로 바꿨다.
- **전체:** 테스트 130개 통과, 빌드와 배포 점검 통과.
- **앱 확인:** 늦은 밤 + 드럼 앤 베이스를 첫 드롭(35초)까지 재생했고 콘솔 오류는 없었다.
- **비교 음원(배포 제외):** `output/playwright/drop-before.wav`, `drop-after.wav`: AB12CD 19–25마디, 전체 믹스.
