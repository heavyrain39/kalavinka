# 테이프 질감 v21 · 로파이 질감 체인 · v0.27.0 / 생성기 v21

장르성을 키우는 작업의 두 번째 단계다. v20까지 세 분위기는 같은 출력 경로를 썼다. 차이는 리버브·딜레이 양 정도였고, 로파이다운 테이프·바이닐 질감은 없었다. v21은 로파이 장면 전체에 테이프 단계를 건다. 악보는 v20과 한 음도 다르지 않고, 소리만 바뀐다.

## 1. 구조 (`src/tape.ts`, `src/audio.ts`)

```
장면 출력(페이드) → 피치 흔들림(wow) → 구동 ×1.25 → 새츄레이션 곡선 → ÷1.25 → 로우패스 → 마스터링
       ↑
  노이즈 베드(히스 + 크래클, 반복 재생)
```

- **장면 전체 통과:** 드럼까지 같은 경로를 지난다. 기본 지연 12ms가 모든 층에 똑같이 걸리므로 층 사이 타이밍(v20 스윙 격자)이 어긋나지 않는다.
- **노이즈 위치:** 노이즈는 장면 페이드 앞에 들어간다. 재생 시작·정지·새 흐름 전환 때 음악과 함께 페이드된다.

## 2. 구성 요소

| 요소 | 내용 | 기본값(온기 72) |
| --- | --- | --- |
| 피치 흔들림 | 0.47Hz(70%)와 0.113Hz(30%) 두 사인으로 지연 시간을 변조. 두 주기가 서로 맞물리지 않아 마디와 겹치지 않는다. 무작위가 아니다 | 최대 약 4.1센트 |
| 새츄레이션 | 원점에서 기울기 1인 tanh 곡선. 약간 비대칭이라 짝수 배음이 섞인다. 2배 오버샘플링 | 보통 음량 -0.3dB, 장면 피크(-12dBFS) -1.25dB |
| 로우패스 | 12dB/oct, Q 0.6 | 10.8kHz |
| 테이프 히스 | 250Hz–4.5kHz 대역 노이즈 | 음악보다 약 45dB 아래 |
| 바이닐 크래클 | 초당 약 8개의 작은 틱과 0.2개의 부드러운 팝. 700Hz–5kHz 대역 | 노이즈만의 피크 -30dBFS |

- **노이즈 버퍼:** 11.3초 길이의 결정적(고정 시드) 버퍼를 끊김 없이 반복한다. 한 번 만들어 장면끼리 공유한다.
- **온기 슬라이더와 연동:** 온기가 노이즈 양·로우패스·흔들림 깊이를 정한다. 재생 중에도 0.12초 램프로 바로 반영된다.
  - 온기 20 이하에서는 노이즈가 0이다.
  - 온기 100에서는 로우패스 8.5kHz, 흔들림 5.5센트가 된다.
  - 새츄레이션 곡선은 장면마다 고정이다(곡선을 바꾸면 클릭이 나기 때문).
- **적용 범위:** 로파이 생성기 v21 이상에만 적용한다. v20 이하 저장곡·공유 링크와 앰비언트·딥하우스·D&B는 그대로다. 재생 중 로파이와 다른 분위기를 오가면 장면을 새로 만든다.

## 3. 조정 과정

- **노이즈 대역:** 첫 시도에서는 히스를 6kHz, 크래클을 상한 없이 두었다. 오디오 분석(earshot)에서 노이즈만 들으면 "타닥거리는 모닥불"로 읽혔다. 히스를 4.5kHz로 낮추고, 크래클을 5kHz 위에서 깎고, 팝을 초당 0.35개에서 0.2개로 줄이고 크기도 낮췄다.
- **새츄레이션:** 처음에는 곡선만 두었다. 장면 피크가 -12dBFS라 사실상 걸리지 않았다. 구동 이득을 넣었더니 곡선 안 구동과 겹쳐 피크가 5dB 가까이 눌렸다. 구동 1.25 × 곡선 1.6으로 다시 맞췄다.

- **테스트:**

  - `tests/browser/tape-render.js`: 실제 엔진 렌더에서 음량 ±1dB 이내, 노이즈 -35dB 이하, 온기 0에서 무음, 소스 누수 없음.
