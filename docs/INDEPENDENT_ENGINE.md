# Kalavinka v0.9.0 — 독자 엔진과 라이선스 전환

## 구현 범위

Strudel의 구현 소스를 복사하거나 Pattern/Cyclist API를 재현하지 않고, 이 앱의 생성 이벤트를 예약하는 두 모듈을 작성했습니다.

- `src/score.ts`: 마디별로 생성한 음표를 캐시하고 `[begin, end)`에 시작하는 이벤트만 반환합니다. 길게 울리는 음을 조회 구간마다 다시 발음하지 않습니다.
- `src/transport.ts`: AudioContext 시각에 고정한 마디→초 변환, 180ms 선행 예약, 다음 안전한 마디의 악보·템포 교체를 담당합니다. 먼저 예약한 범위를 소급해서 덮어쓰지 않습니다. 빠른 연속 변경은 아직 예약되지 않은 변경만 대체합니다.
- AudioWorklet은 약 45ms마다 예약기를 깨웁니다. UI 애니메이션은 시간 기준이 아닙니다. 실제 발음 시각은 Web Audio에 미리 전달됩니다.
- 긴 메인 스레드 정지에서는 놓친 음을 몰아서 재생하지 않고 오디오 시각에 다시 맞춥니다. 180ms를 넘는 실행 지연이나 기기 절전에도 연속음을 보장한다는 뜻은 아닙니다.
- 이미 울리기 시작한 음은 발음 시점의 길이·템포를 유지합니다. 다음 마디의 새 음부터 새 템포를 사용합니다. 과거 소리의 시간 늘이기 기능은 추가하지 않았습니다.
- 예약 시점의 합성 설정과 화면에 표시하는 현재 설정을 분리했습니다. 연속 새 흐름·정지·재생 시의 장면 정리도 보강했습니다. 정지 시 아직 ended 이벤트를 받지 못한 음원까지 명시적으로 해제합니다.
- 16개 악기의 합성·배음·엔벌로프 값과 잔향·딜레이·EQ·컴프레서 설정, 음악 생성기 v1–v5는 유지했습니다. 합성 모듈의 변경은 음원 수명 관리에 한정됩니다.

## 비교·검증

기준: v0.8.0, commit `54cd8a16d6765179f6754547d4e75f3b21adcc2b`, Strudel core 1.2.6.

1. 제거 전에 기존 패키지를 실행하여 출력만 기록했습니다. 36개 설정(생성기 v1–v5, 세 분위기, D&B, 최저·최고 템포)의 64마디 총 26,737개 이벤트가 대상입니다. `tests/fixtures/strudel-v080.json`에는 이벤트 SHA-256과 시각·길이 수치가 들어 있으며 Strudel 구현은 들어 있지 않습니다.
2. 새 Score의 이벤트 데이터는 기존 출력과 동일합니다. 시작 시각·음 길이는 0.1µs 이내로 일치합니다. 별도로 기존 Cyclist를 가상 오디오 시계에서 실행한 발음 시각·길이와 새 Transport를 비교합니다.
3. 템포 연속 변경, 예약 경계의 중복·누락, 장시간 시계 점프, 오류 시 정지, 아직 들리지 않은 미래 구간의 합성 설정을 검증합니다.
4. Chromium/48kHz OfflineAudioContext에서 생성기 v1–v5 × 세 분위기의 15개 4마디 구간을 비교했습니다. 구버전 자체 재렌더링의 최대 샘플 차이는 0.000716, 차이 RMS 최대 0.0000324였고, 신구 비교에서는 각각 0.000515와 0.0000263 이하였습니다. 이 표본에서는 기존 렌더링 편차와 비슷한 수준이었습니다. 샘플의 완전 일치나 모든 브라우저·장치에서의 청감 동일성을 주장하지 않습니다.
5. 실제 AudioContext에서 170→90→180 연속 변경, 변경 대기 중 리버브 조절, 연속 재생성, 시작 직후 정지, 타이머 정지를 확인했습니다. 늦은 발음 0, 오류 0, 정지 후 활성 소스 0.
6. `npm test`, `npm run build` 및 `tests/browser/transport.js`로 재검증할 수 있습니다. 빌드 후 감사는 잠금 파일·배포 JavaScript의 Strudel/fraction 제거와 이용 조건·외부 고지 파일을 확인합니다.

## 라이선스 경계

현재 Git 기록의 작성자는 Yakshawan이며, 앱 소유자의 요청에 따라 자체 코드의 새 배포 조건을 변경했습니다. 새 라이선스는 법률적 권리 보유를 새로 만들어내는 수단이 아닙니다. 확인되지 않은 외부 권리나 미래 기여가 있다면 별도 확인이 필요합니다.

- v0.9.0부터 `LICENSE`의 Kalavinka Proprietary License를 적용합니다. 공식 웹앱의 무료 사용·청취는 허용하며, 소프트웨어 재사용·수정·재배포·별도 서비스에는 별도 서면 허락이 필요합니다.
- v0.8.0 및 그 이전에 이미 AGPL로 배포한 코드의 권리는 유지됩니다. 이전 코드를 새 조건으로 소급 제한하거나 Git 기록을 삭제하지 않습니다.
- 공개 GitHub 저장소에 적용되는 약관상 열람·포크 권한을 제한하지 않습니다. 공개 저장소와 배포 JavaScript를 기술적으로 숨기는 변경은 아닙니다.
- 폰트는 OFL, Mastermind에서 가져온 피크 곡선·시각화 부분과 Vite의 배포 헬퍼는 MIT 고지를 보존합니다. 별도 라이선스는 해당 부분에 계속 적용됩니다.
- 현재 배포물에는 Strudel 또는 fraction.js가 포함되지 않습니다. 이전 버전의 해당 고지는 원래 커밋에 남습니다.
