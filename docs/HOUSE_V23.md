# 하우스 음색 v23 · 딥하우스 밝은 스탭과 필터 흐름 · v0.29.0 / 생성기 v23

장르성을 키우는 작업의 네 번째 단계다. 대상은 늦은 밤의 포 온 더 플로어(딥하우스)뿐이다. v22까지 딥하우스 화음은 고역이 거의 없었다. 그래서 펌핑도 필터 흐름도 잘 들리지 않았다. v23은 화음·멜로디·아르페지오 음색을 밝히고, v22에서 미뤘던 구간별 필터 흐름을 다시 넣는다. 음 높이와 타이밍은 v22와 한 음도 다르지 않다. 바뀌는 것은 음색, 각 파트의 cutoff, 화음 음량뿐이다.

## 1. 밝은 화음 음색 (`src/synth.ts`, `src/comping-v18.ts`)

딥하우스 장면의 화음 층에만 적용한다.

| 악기 | v22 | v23 |
| --- | --- | --- |
| 오르간 | 저차 배음 위주 | 16배음까지 드로바 배음과 3kHz 키 클릭 |
| 일렉트릭 피아노 | FM 지수 낮음 | FM 지수 1.5, 감쇠 0.38, 3배음 추가 |
| 패드 | 사인 위주 | ±7센트로 디튠한 톱니파 두 개 추가 |
| 펠트 피아노 | 기본 배음 | 5·6배음 추가 |

- **필터 닫힘:** 음이 울리는 동안 필터가 닫히는 정도를 50%에서 80%로 바꿨다. 스탭의 머리가 덜 둔해진다.
- **cutoff:** 화음은 `7000 - 온기 × 45`, 멜로디는 `5200 - 온기 × 28`, 아르페지오는 `2600 + (100 - 온기) × 30`이다. 딥하우스 기본 온기 62에서 화음은 1774 → 4210Hz, 멜로디는 2160 → 3464Hz, 아르페지오는 2070 → 3740Hz가 된다.
  - 온기를 올리면 여전히 어두워진다.
  - v18의 마디별 반주 필터 변화는 그대로 둔다.
- **화음 음량:** 스탭이 짧고 드물어서 믹스에 묻혔다. 화음 음량을 1.35배로 올렸다.

## 2. 구간별 필터 흐름 (`src/house-v23.ts`, `src/audio.ts`)

음악 버스의 펌핑 앞에 로우패스(Q 0.7)를 둔다. 32마디 편곡 흐름을 따라 마디마다 지수 곡선으로 움직인다.

| 구간(32마디 안) | cutoff |
| --- | --- |
| 인트로 0–7 | 1000Hz에서 열리기 시작해 7마디에서 완전히 열림 |
| 그루브 8–15 | 완전히 열림 |
| 브레이크다운 16–19 | 900Hz로 닫힘 |
| 빌드업 20–23 | 1200 → 2000 → 3600 → 7000Hz |
| 그루브 24–29 | 완전히 열림 |
| 끝 30–31 | 4000 → 1800Hz |

- **경로:** 드럼과 베이스 원음은 이 필터를 지나지 않는다. 킥과 베이스는 늘 꽉 차 있고, 그 위의 음악만 열리고 닫힌다.
- **위치 계산:** 새 흐름이나 문구 전환으로 재생 위치가 바뀌어도, 원래 악보의 마디 번호(`sourceBar`)로 흐름을 정한다. 처음 시작한 마디에서는 곧바로 그 값으로 맞춘다.
- **적용 범위:** 딥하우스 v23에서만 켜진다. 로파이·앰비언트·D&B와 v22 이하 곡은 그대로다. 딥하우스와 다른 리듬·분위기를 오가면 장면을 새로 만든다.

## 3. 측정

**화음 층만(ZK9Q, 그루브 8마디, `tests/browser/house-render.js`).** 3kHz 위 에너지가 전체 화음 신호에서 차지하는 비율이다.

| 악기 | v22 | v23 | 음량 변화 |
| --- | --- | --- | --- |
| 오르간 | -104.5dB | -50.8dB | +1.1dB |
| 일렉트릭 피아노 | -73.0dB | -58.7dB | +1.6dB |
| 패드 | -91.0dB | -63.6dB | +1.6dB |
| 펠트 피아노 | -76.4dB | -62.0dB | +1.6dB |

**음악 버스(드럼·베이스 제외, ZK9Q, 2마디씩).** 2kHz 위 에너지다.

| 구간 | v22 | v23 |
| --- | --- | --- |
| 인트로 0–1마디 | -79.9dB | -79.8dB |
| 인트로 6–7마디 | -79.2dB | -69.0dB |
| 그루브 10–11마디 | -78.8dB | -63.3dB |
| 브레이크다운 16–17마디 | -101.6dB | -84.4dB |
| 빌드업 21–22마디 | -85.5dB | -67.5dB |

- **음악 버스에서는 흐름이 분명하다.** 인트로 첫 마디는 v22만큼 어둡게 시작한다. 그루브에서는 15dB 넘게 밝아진다. 브레이크다운에서는 그루브보다 21dB 닫혔다가 빌드업에서 다시 열린다. 버스 전체 음량 차이는 1.1dB 이하다.
- **전체 믹스에서는 은은하다.** 2–5kHz 대역은 하이햇과 드럼이 차지한다. 그래서 인트로 처음과 끝의 프레즌스 차이가 v22와 거의 같다(약 0.1dB). 스탭이 많은 시드(ZK9Q)에서는 믹스 밝기 중심이 606 → 788Hz로 올라간다. 스탭이 2마디에 두 번뿐인 시드(SLOWFLOW)에서는 분석 도구가 거의 같은 소리로 판정한다.
- **통합 음량:** 음악 버스는 v22와 같다(-22.9 → -23.0 LUFS, SLOWFLOW).

## 4. 검증

- **`tests/house-v23.test.ts`:**
  - 로파이·앰비언트·D&B의 v23 악보가 v22와 같다.
  - 딥하우스에서는 음 높이·타이밍이 같고, 화음 음량·cutoff와 멜로디·아르페지오 cutoff만 바뀐다.
  - 버전·분위기 게이트가 맞다.
  - 필터 흐름이 인트로에서 열리고, 그루브에서 열려 있고, 브레이크다운에서 닫혔다가 빌드업에서 열린다.
- **`tests/browser/house-render.js`:** 네 화음 악기 모두 3kHz 위 비율이 6dB 넘게 오르고, 음량은 4dB 넘게 오르지 않는다. 소스 누수와 비정상 값이 없다.
- **앱 확인:**
  - 딥하우스 재생 중 필터가 1043 → 4814Hz로 마디마다 열린다.
  - 새 흐름 뒤에도 흐름을 이어 간다.
  - D&B와 로파이에서는 필터가 없다.
  - 정지 후 활성 소스 0, 콘솔 오류 없음.

  - `house-v23-intro-before.wav`, `house-v23-intro-after.wav`: 음악 버스만, 인트로 8마디
