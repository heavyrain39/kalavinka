# 고요한 공간 v13 · v0.19.0

2026-10-04. [원인 조사와 제안](AMBIENT_SOUND_REVIEW_2026-10-04.md)에 따른 음향 개선이다.

## 달라진 소리

- 패드·오르간의 공통음을 2마디 단위로 겹쳐 연결한다. 동일 화음을 다시 칠 때 생기던 건조 신호의 빈틈을 줄인다. 다른 화음으로 바뀌는 음은 경계 근처에서 끝나도록 별도 릴리스를 쓴다. 무제한 유지음 대신 짧은 구간을 연결하여 편곡 변경과 저장 악보의 범위를 유지한다.
- 패드는 느린 곡선 어택과 코사인 곡선 릴리스, 더 약하고 느린 비브라토를 사용한다. 벨의 높은 비조화 배음을 줄이고 짧은 음표 뒤 감쇠를 늘린다. 벨 아르페지오의 기본 릴리스는 0.85초, 멜로디 벨은 1.25초다. 이웃음과 화성 경계에서는 충돌을 줄이도록 더 일찍 끝낸다. 마림바·플루트·건반도 앰비언트용 감쇠를 사용한다.
- 초기 반사, 스테레오 확산, 대역별 감쇠를 가진 5.8초 길이의 절차적 임펄스 응답을 로컬에서 생성해 캐시한다. 5.8초는 버퍼 길이이며 실측 RT60을 뜻하지 않는다. 중역보다 저역·고역이 먼저 감쇠한다.
- 화음·멜로디·아르페지오·베이스의 공간 전송량을 각각 조절한다. 베이스 전송은 낮게 유지하고 기존 템포 딜레이는 새 앰비언트에서 끈다. 프리딜레이는 12ms다.
- 기본 리버브 28에서 분위기를 고르면 고요한 공간 기본값 76을 적용한다. 직접 조절한 값은 유지한다. 슬라이더는 계속 잔향량을 조절한다.
- 앰비언트를 포함하는 새 흐름 전환은 1.6초 동안 교차 페이드한다. 정지 시에는 기존처럼 빠르게 페이드하고 모든 음원을 해제한다.

새 음향은 `profile=ambient`, `generatorVersion>=13`에만 적용한다. v12 이하 저장곡과 링크의 악보 및 음향 분기를 보존한다. 다른 분위기의 v13 악보는 v12와 동일하다. 기존 곡에서 새 음향을 쓰려면 분위기를 다시 선택하거나 새 흐름을 만든다. 이전에 직접 정한 리버브 값은 기본값 버튼으로 복원할 수 있다.

## 검증

- Node 테스트 63개 통과. v12 네 모드의 64마디 지문, 다른 분위기의 v13 동일성, 패드 공통음/화성 경계, 아르페지오의 기존 진입 시점·음정, 저장 악보 직렬화와 복원을 확인했다.
- TypeScript, 프로덕션 빌드, 배포 라이선스 검사 통과.
- 실제 Chrome에서 180 BPM으로 8마디 이상 재생하고 구절 저장·새로고침·복원·새 흐름·다른 분위기 전환·정지를 확인했다. 지연 음표 0, 페이지 오류 0, 정지 후 음원 0.
- 48kHz 오프라인 렌더 8개: 50/180 BPM × 패드/오르간/펠트/전자 건반, 에너지·변화·리버브·볼륨 최대. 모든 샘플 유한값, 최대 피크 0.651 미만, 렌더 완료 후 음원과 정리 콜백 0.
- v12↔v13 전환과 100ms 간격의 연속 새 흐름 후 정지·재시작을 확인했다. 7개 씬 모두 해제, 남은 음원 0, 재시작 지연 음표와 오류 0.
- 고정 seed `SLOWFLOW`, 64 BPM, 16마디와 여운을 포함한 67초 비교 WAV를 `output/playwright/ambient-before.wav`, `ambient-after.wav`에 만들었다(배포 제외). 이전 기본값(v12, 리버브 28)과 새 기본값(v13, 리버브 76)의 전체 출력을 동일 RMS 0.08로 맞췄고, 조정 후 피크는 각각 0.387/0.422 미만이었다. 특정 변경 하나의 효과를 분리하는 실험이나 LUFS 일치는 아니다. 이 PC의 오프라인 씬 생성은 기존 16.5ms, 새 임펄스 생성 포함 71.3ms였다. 모바일 성능의 보장은 아니다.

## 범위

외부 샘플과 새 패키지를 추가하지 않았다. 이번 변경은 합성음의 감쇠·화음 연결과 공간 처리에 집중했다. 실측한 안정성과 클리핑 여부를 청취 선호의 증명으로 보지 않는다. 실제 악기 멀티샘플 채택, 긴 청취 비교에 따른 음색 선택, 실기기별 장시간 성능 평가는 후속 범위다.
