# 멜로디 v35 · 나머지 분위기의 반복을 줄임 · v0.43.0 / 생성기 v35

v34는 따뜻한 책상(에너지 30 이상)의 계단식 반복만 줄였다. "반복이 많아졌다"는 피드백은 전체 분위기를 두고 한 말이었으므로, 고요한 공간, D&B, 늦은 밤, 에너지 30 미만의 멜로디도 같은 원칙(한 문장에 되풀이는 한 곳)으로 고쳤다.

따뜻한 책상(에너지 30 이상)은 v34와 한 음도 다르지 않다. 드럼, 화음, 베이스 규칙도 그대로이고 v34 이하 곡의 악보도 그대로다.

## 1. 진단 (v32–v34)

v34 문서는 성긴 문법에 계단이 "측정 0%"라고 적었는데, 반 마디 단위로만 쟀기 때문이다. 성긴 분위기는 한 마디에 한두 음이라 되풀이가 **마디 단위**로 생긴다. 마디 단위로 다시 쟀다(16개 시드 × 256마디, 멜로디 반복성 보통).

### 성긴 문법 (고요한 공간, D&B, 에너지 30 미만)

| 항목 | 분위기 | v31 | v32–v34 |
| --- | --- | --- | --- |
| 응답(3–4마디)의 리듬이 제시(1–2마디)와 같음 | 고요한 공간 | 55% | 98% |
| | D&B | 45% | 90% |
| | 따뜻한 책상 에너지 25 | 42% | 89% |
| 8마디에서 가장 흔한 마디 리듬의 횟수 | 고요한 공간 | 3.4 | 3.9 |
| | D&B | 3.3 | 4.2 |
| 같은 리듬이 이어지는 가장 긴 마디 수 | 고요한 공간 | 1.3 | 2.4 |
| | D&B | 1.3 | 2.5 |

v32의 성긴 문장은 "셀 한 마디, 긴 음 한 마디"를 제시하고, 응답이 그 리듬을 그대로 받고, 전개가 5마디(절반은 6마디에도)에 셀을 다시 냈다. 셀이 첫 박 한 음인 주제에서는 여섯 마디 내내 첫 박에 한 음씩 올라가는 줄이 되었다.

### 하우스 리프 (늦은 밤)

| 항목 | v31 | v32–v34 |
| --- | --- | --- |
| 8마디에서 가장 흔한 마디 리듬의 횟수 | 6.2 | 5.7 |
| 같은 리듬이 이어지는 가장 긴 마디 수 | 6.0 | 5.6 |
| 앞 마디와 음까지 똑같은 마디 수 | 2.2 | 3.0 |

한 마디 리프를 네 번 그대로, 두 번 올려서, 한 번 더 냈다. 리듬의 되풀이는 v31과 비슷하지만 v31은 높이를 바꿔 가며 되풀이했고 v32는 음까지 똑같은 마디가 늘었다.

## 2. 규칙 (`src/melody-v32.ts`, `melodyV35`)

### 성긴 문법

- **둘째 셀:** 주제마다 첫 셀과 리듬이 다른 한 마디 셀을 하나 더 갖는다.
- **응답은 세 가지 중 하나다.** 문장마다 고른다.
  - 40%: v32처럼 제시의 리듬을 따르고 끝만 반대로 돌린다.
  - 40%: 둘째 셀을 쓰고, 긴 음이 제시와 다른 자리(같은 마디 3박, 또는 다음 마디 2박)에 온다.
  - 20%: 제시의 셀을 그대로 내고 긴 음이 바로 뒤따른다. 다음 마디는 비운다. 셀이 마디 뒤쪽까지 가는 주제에서는 둘째 방식으로 바꾼다.
- **전개:** 응답이 셀을 다시 냈으면(첫째·셋째 방식) 전개는 셀 대신 둘째 셀이 올라가 정점에 닿는다. 응답이 둘째 셀이었으면 v32의 전개(셀을 한두 번 올림)를 그대로 쓴다.
- 둘째 셀은 전개가 오를 높이보다 낮게 둔다.

### 하우스 리프

- **리프가 두 마디다.** 첫 마디는 v32의 리프 마디 그대로다. 둘째 마디는 주제에 따라 둘 중 하나다.
  - 절반: 머리는 같고, 꼬리 대신 다른 박에 긴 음 하나가 온다.
  - 절반: 둘째 셀(다른 리듬, 다른 모양)로 답하고 긴 음으로 끝난다.
- **문장:** 두 마디 리프, 그대로 한 번 더, 변화(한두 단계 올림·한 음 바꿈·둘째 리프), 리프 첫 마디와 마침. v32는 한 마디를 네 번, 올려서 두 번, 다시 한 번이었다.
- 둘째 마디의 긴 음은 마디의 4박 앞에서 끝나 한 박을 쉰다. 한 마디 리프가 마디마다 쉬던 자리를 두 마디에 한 번으로 모은 것이다.

### 손대지 않은 것

- 셀 문법(따뜻한 책상, 에너지 30 이상)은 v34 그대로다.
- 제시(1–2마디), 정점, 마침음 자리, 종지, 세기와 길이, 탐색기의 비용, 반주·베이스·드럼.

### v32에서 얻은 것 (`scripts/music-metrics.ts`)

| 항목 | 분위기 | v31 | v34 | v35 |

| 가장 높은 음이 4마디 후반–7마디 전반에 처음 나옴 | 고요한 공간 / 늦은 밤 / D&B | 82 / 79 / 82% | 85 / 85 / 83% | 83 / 84 / 81% |
| 마디당 음 수 | 고요한 공간 / 늦은 밤 / D&B | 0.98 / 2.31 / 0.84 | 1.07 / 2.47 / 0.91 | 1.06 / 2.45 / 0.91 |
| 문장의 음역(반음) | 고요한 공간 / 늦은 밤 / D&B | 6.1 / 7.0 / 6.5 | 7.5 / 6.8 / 7.4 | 7.6 / 7.8 / 7.5 |

- **첫 시도의 부작용:** 리프 둘째 마디의 긴 음을 마디 끝까지 울렸더니 늦은 밤의 쉼이 75% → 17%로 줄었다. 긴 음을 4박 앞에서 끊어 92%가 되었다.
- **정점:** 늦게 나오는 비율이 1–2%p 낮아졌다. 응답이 새 음형을 쓰면서 앞쪽이 조금 높아지는 경우가 있다. v31보다는 높거나 같다.
- **한계:** 수치는 악보에서 잰 값이고 귀로 듣고 고른 결과가 아니다. 들어 보고 응답의 방식 비율(40 / 40 / 20)과 리프 둘째 마디의 비율(50 / 50)을 조정할 수 있다. 하우스는 v31보다도 덜 되풀이하므로, 리프의 끈기가 부족하게 들리면 머리를 지키는 쪽의 비율을 올리면 된다.

## 4. 검증

- **`tests/melody-v35.test.ts` (7개):**
  - v34 곡 96마디의 악보 해시(4개 분위기 × 반복 끔·보통)가 v35 도입 전 기록과 같다.
  - 따뜻한 책상(에너지 기본·70)은 v34와 악보가 같다. 나머지 분위기는 리드만 바뀌고 드럼과 화음은 v34와 같다.
  - 성긴 문법: 응답이 제시의 리듬을 따르는 문장이 20–60%(v34는 80% 초과), 가장 흔한 마디 리듬과 같은 리듬의 연속이 v34보다 뚜렷하게 줄고, 마디당 음 수는 v34의 ±10% 안이다.
  - 하우스: 1–2마디가 서로 다르고 3–4마디에 되돌아오는 문장이 85% 초과(v34는 15% 미만), 같은 리듬의 연속 1.6마디 미만, 똑같은 마디 2개 미만.
  - 다섯 설정 모두 A–B–A 13% 미만, 쉼 78% 이상, 정점이 5–8마디에 70% 이상, 마침음 세 자리, 한 마디의 리드 음 6개 이하.
  - 모든 음이 화음 음계 안에 있고, 경과음이 2도로 해결되고, 6도 넘는 도약이 없다. 고요한 공간을 뺀 분위기는 화음이 바뀌기 전에 끝난다(고요한 공간의 긴 여운은 v30의 의도이고 v34와 같다).
  - 늦은 밤, D&B, 고요한 공간에서 멜로디 반복성 단계의 순서, 임의 접근, 캐시 교체, 저장한 8마디, 파트 끄기.
- **전체:** 테스트 178개 통과, 빌드와 배포 점검 통과.
- **앱 확인:** 늦은 밤과 D&B가 생성기 v35로 재생되고 늦은 스케줄 0건, 오류 없음.
