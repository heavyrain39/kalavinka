# 합주 v3: 선택 가능한 음색과 공동 패턴 계획

2026-10-03 · 앱 v0.4.0 · generatorVersion 3

## 음색과 사용 흐름

| 파트 | 선택 |
|---|---|
| 화음 | 펠트 건반, 일렉 피아노, 오르간, 스트링 패드 |
| 베이스 | 라운드, 서브, 플럭 베이스, 아날로그 |
| 리듬 | 브러시, 테이프 킷, 일렉트로, 미니멀 킷 |
| 멜로디 | 벨, 마림바, 소프트 플루트, 플럭 |

오실레이터·FM·절차적으로 만든 노이즈와 필터·엔벌로프를 조합한다. 외부 음원 파일은 없다. 리듬 킷은 음색, After hours의 Four on the floor / Drum & bass는 타격 배치다. 서로 독립적으로 선택한다. D&B 선택은 170 BPM, 기본 리듬 복귀는 108 BPM으로 바꾸며 이후 50–180 BPM 범위에서 조절한다. D&B의 킥은 매 박 대신 16분 그리드의 0/6/10, 0/7/10 등으로 변형한다. 스네어는 2·4박, 하이햇은 구간·에너지에 따라 세분한다. 도입·비트 없는 비움·복귀도 유지한다.

새 흐름은 이전 음색 ID를 후보에서 제외해 네 파트를 모두 변경한다. 장르별 가중 선택과 밝은 건반/벨 조합의 가중치 완화를 사용한다. 직접 고른 음색은 다른 파트를 자동 변경하지 않는다. ID를 설정에 명시적으로 저장하므로 시드뿐 아니라 전체 설정이 재현 단위다.

## 수학적 구성

1. **공통 시간:** 모든 파트가 `T(bar, step)`을 사용한다. 로파이는 동일한 스윙 오프셋을 적용하며, 16분음표의 위치와 악센트를 공유한다.
2. **균등 분산:** `floor((i+1)k/n) > floor(ik/n)`인 위치를 선택하고 회전한다. 순환 간격은 `floor(n/k)` 또는 `ceil(n/k)`다. 리듬 골격과 하이햇·아르페지오에 사용하며, 모든 파트를 같은 패턴으로 만들지는 않는다. 관련 원리: Godfried Toussaint, [The Euclidean Algorithm Generates Traditional Musical Rhythms (2005)](https://cgm.cs.mcgill.ca/~godfried/publications/banff.pdf). 구현은 균등 분산식이며 Bjorklund 알고리즘 자체를 이식한 것은 아니다.
3. **의존 순서:** 드럼 위치를 먼저 정한 뒤 화음·베이스, 멜로디를 배치한다. 로파이는 공통 다운비트로 결속하고, 전자 리듬의 베이스는 실제 킥 onset에서 85 ms 이상 떨어진 후보를 고른다. 킥이 베이스 버스를 덕킹한다. 다른 주요 타격 두 개가 겹치면 선택적 하이햇을 제거한다.
4. **코드 보이싱:** 장·단조 각각 여섯 진행, 열두 조. 네 성부의 이동량 합과 중앙 음역 이탈 비용을 최소화한다. 마지막→첫 코드 이동 비용을 포함하는 동적 계획법을 사용한다. 후보 음역 52–79, 성부 교차 금지.
5. **선율 최적화:** 4마디 리듬 슬롯을 먼저 확정한 후 코드톤 후보 경로를 찾는다. 비용은 `0.6×윤곽 이탈 + 0.1×음역 이탈 + 베이스 충돌 + 0.24×이동량 + 큰 도약·동음 반복 비용 + 작은 시드 변이`다. 인접 이동 7반음 이하, 처음/끝 음은 공통 중심 ±3반음으로 제한한다. 최근 두 음을 DP 상태에 보존해 세 번 연속 반복도 평가한다. 경과음은 약박에서만 허용하고 다음 코드톤으로 2반음 이내 해결한다.
6. **시간적 여백:** A/A′/전개/턴어라운드 윤곽, 마지막 마디의 쉼, 아르페지오 구간을 사용한다. 베이스 게이트는 다음 음 앞에 80 ms, 선율은 140 ms의 릴리스 여유를 둔다. 음색·음소거·볼륨은 악보 캐시 키에서 제외한다.

비용과 가중치는 작곡 휴리스틱이다. 음계·도약·타이밍 제약은 검사할 수 있지만 청취 취향이나 음악적 완성도를 수학적으로 보장하지 않는다. 실제 PCM은 브라우저 DSP에 따라 차이가 있다.

## 호환성과 런타임

기존 v1·v2 악보/음색 경로를 보존한다. 정규화에서 버전 없는 기존 시드 링크는 v1이다. 일반 세션은 v3로 업그레이드하고, 저장한 음악/공유 링크는 원래 버전을 유지한다. 음색 직접 변경은 v3 선택으로 간주한다. 재생 중 음색 변경은 다음 마디부터 적용한다. 새 흐름과 장르/리듬 선택은 기존 장면 전환 페이드를 사용한다. 마스터링은 모든 버전에 공통이다.
