# 베이스와 D&B 개선 — v0.5.0 / 생성기 v4

2026-10-03

## 원인

이전 생성기는 전자 계열 베이스 첫 위치를 대개 16분 그리드의 2로 고정하고, 음높이를 근음→5음→3음 순으로 선택했다. 에너지 기본값에서는 로파이/덥/D&B 모두 4마디당 12음으로 수렴했다. 앰비언트는 짝수 마디의 근음/5음과 두 가지 길이로 거의 고정돼 있었다. 시드가 타격 위치를 바꾸더라도 선율의 특징은 잘 달라지지 않는 구조였다.

D&B는 같은 덥 편곡을 170 BPM으로 올리는 수준이었다. 킥 패턴과 하이햇 위상이 마디마다 바뀌고, 멜로디도 매 마디 별도로 위치를 고르며 화음은 짧게 두 번씩 타격했다. 음계에 맞는 음이라도 여러 파트가 동시에 짧게 변해 알아들을 수 있는 프레이즈가 약해졌다.

## 변경

- 모든 장르에 여덟 베이스 리프 계열. 네 마디의 A/B/A/B′ 리듬, 근음 반복·옥타브·5음·3음 등 서로 다른 윤곽, 계열별 게이트와 악센트를 함께 선택한다. 고정 1–5–3 순서를 제거한다.
- 앰비언트는 별도 여덟 배치에서 2–4개의 긴 음, 지연 진입, 빈 마디를 사용한다. 비움에서는 일부 응답을 쉬고 복귀에서는 짧은 응답을 더한다.
- 도입·비움·복귀의 밀도와 응답을 조정하되 곡의 기본 리프를 유지한다. ‘변화’로 다음 폼의 변형을 허용한다. 무작위 재추첨을 매 음에 적용하지 않는다.
- 전자 베이스의 위치는 리프 목표 위치에서 가장 가까운 유효 위치로 옮긴다. 실제 킥 onset과 85 ms 이상 간격을 둔다. 음이 킥 아래까지 이어질 경우 기존 버스 덕킹이 작동한다. 전체 베이스를 킥 사이에 완전히 잘라 넣는 규칙은 아니다.
- 베이스 릴리스가 다음 음·다음 코드·프레이즈 경계를 넘지 않도록 제한한다. 170–180 BPM에서 늦은 16분음표를 이동시키는 경우도 검사해, 최소 엔벌로프 길이를 확보할 수 없는 위치는 제외한다.
- D&B는 두 마디 킥 반복, 고정 8분 하이햇과 2·4박 스네어. 고에너지일 때 8마디 끝에만 필인을 둔다. 핵심 하이햇은 일반 밀도 삭제 규칙에서 제외한다.
- D&B 코드 유지 2→4마디, 같은 화음의 재타격은 두 마디마다. 멜로디는 세 가지 질문·응답 틀에서 골라 기본 구간에 네 마디당 최대 5음. 비움에서는 느린 아르페지오와 쉼을 번갈아 사용한다.
- 선율의 예상 지속 구간에 겹치는 베이스 음들을 함께 평가하며, D&B의 오래 겹치는 반음·장7도·트라이톤 비용을 강화한다. 이는 소프트 비용이며 모든 불협화음을 금지하는 규칙은 아니다.
- D&B의 딜레이 간격은 두 배로, 믹스는 .19→.09로 줄여 빠른 반복음이 프레이즈를 가리지 않게 한다. UI 코드 진행 표시도 실제 네 마디 유지에 맞춘다.

## 비교와 검증

동일 64시드, 8–11마디, 기본 장르 에너지에서 측정했다. 음정열은 각 베이스 음을 해당 화음 근음에 대한 피치 클래스로 변환한 배열이다. 배열 길이의 차이도 포함하므로 아래 수치가 독립적인 작곡 스타일 수를 뜻하지는 않는다.

|---|---:|---|
| 로파이 | 12→53 | 12→6/7/10/11 |
| 앰비언트 | 3→9 | 2→2/3/4 |
| 덥 | 12→52 | 12→6/7/10/11 |
| D&B | 12→44 | 12→6/7/10/11 |

D&B의 같은 구간은 평균 멜로디 9.25→5음, 화음 타격 8→2회. 타격 길이의 무작위 조합 수를 무조건 늘리는 대신 식별할 수 있는 리프의 길이 패턴을 반복한다. 수치가 음악적 취향이나 청취 품질 자체를 증명하지는 않는다.
