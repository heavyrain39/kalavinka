# 멜로디 반복성 · v0.20.0 / 생성기 v14

멜로디의 반복·발전 구조를 `끔 / 약 / 보통 / 강` 네 눈금으로 조절한다. 기본값은 보통이다. 기존 변화 슬라이더는 모티프 내부 변주의 폭과 빈도를 담당하며, 반복성은 음형 재사용과 테마 유지 기간을 담당한다.

| 단계 | 동작 |
| --- | --- |
| 끔 | 두 마디마다 독립된 음형을 만든다. 이전 테마 인용을 끈다. 멜로디는 계속 연주한다. |
| 약 | 짧은 테마의 리듬과 앞부분 특징을 재사용하면서 뒷부분의 음형을 자주 바꾼다. 일반/D&B 16마디, 앰비언트 32마디마다 다음 테마로 넘어간다. |
| 보통 | 기존 v13 멜로디와 동일하다. 일반/D&B 64마디, 앰비언트 128마디 동안 모티프를 반복·발전한다. |
| 강 | 일반/D&B 128마디, 앰비언트 256마디 동안 테마를 유지한다. 발전 구간의 리듬 이동과 큰 윤곽 변형을 줄이고 음 생략 빈도를 낮춘다. |

모든 단계에서 화음에 맞는 음 선택, 8마디의 마무리, 템포 예약 규칙을 유지한다. 강도는 반복 정도를 뜻하며 볼륨이나 음표 밀도가 아니다. `끔`도 음계와 리듬 후보를 공유하므로 우연한 반복까지 금지하지는 않는다.

## 상태와 호환성

- `melodyRepetition: 0|1|2|3`은 생성기 v14부터 사용한다. 이전 버전은 새 필드를 무시하고 기존 악보를 유지한다.
- 보통은 v13의 악보와 일치한다. 새 곡과 업그레이드는 보통으로 시작하며, v14에서 선택한 값은 분위기 변경·새 흐름에도 유지한다. 기본값 버튼은 보통으로 되돌린다.
- 스코어 캐시 키에 단계를 포함한다. 저장한 8마디 악보, 공유 링크, 새로고침 복원에 설정을 포함한다. 기존 저장곡에서 슬라이더를 움직이면 최신 생성기로 업그레이드하고 다음 예약 마디부터 새 설정을 적용한다.
- 아르페지오의 진입·음정·길이는 그대로다. 기존 멜로디 겹침 감지에 따른 아르페지오 레벨 보정은 새 멜로디 위치를 따른다.
- 슬라이더는 네 정수 값에 고정된다. 화살표·Home·End 키를 지원하고 한국어/영어 `aria-valuetext`로 단계를 읽는다. 눈금 아래 단계명과 현재 값을 함께 표시한다.

## 검증

Node 테스트 67개와 TypeScript·프로덕션 빌드·라이선스 검사를 통과했다. 새 테스트는 보통의 v13 악보 동일성, 역사 버전 분리, 반주 보존, 마무리 음, 저장 악보 복원, 캐시 교차 조회, 설정 정규화·초기화를 확인한다. 네 모드·여덟 시드·256마디의 집계에서 단계가 높을수록 연속 구절의 도입 리듬이 더 자주 유지되는지 검증한다.

Chrome에서 키보드 네 단계 조절, 저장·새로고침·공유·불러오기·기본값 복원을 확인했다. 180 BPM 재생 중 각 단계가 다음 마디에 반영되며 지연 음표와 페이지 오류는 0이었다. 한국어·영어 각각 1440, 1280, 1024, 900, 390, 320px 화면에서 가로 넘침이 없었고 데스크톱·모바일 스크린샷을 확인했다.

## 생성기 v17 변경 · v0.25.0

'보통'이 지나치게 반복적으로 들린다는 청취 의견에 따라 v17에서 단계별 테마 길이와 동작을 다시 정했다. 일반은 끔 8, 약 16, 보통 32, 강 64마디이고, 앰비언트·D&B는 그 두 배다. '보통'은 문장마다 발전 기법과 응답이 바뀌고, 셋째 문장은 대비 동기로 시작한다. '강'은 v16 '보통'에 가까운 반복감을 낸다. v14–v16 저장곡은 위 표의 규칙을 그대로 유지한다. [음악 기획서 v17](MUSIC_V17.md)
