# v0.11.0 / 생성기 v6 — 드럼 제작·표현·믹스

## 음색과 연주

`drum-bank.ts`는 직접 작성한 합성기로 킥의 타격·몸통·피치 감쇠, 스네어의 두 공명·와이어 노이즈·짧은 크랙, 하이햇의 비정수 배음·금속성 상호작용·노이즈를 각각 구성한다. 네 킷 × 하우스/D&B × 일곱 타격 종류 × 세 강약 × 두 변형 = 336개 모노 버퍼다. 킥·스네어는 개별 포화를 포함하고, 2배 샘플레이트에서 합성 후 DC 제거·저역 통과·다운샘플링·끝 페이드를 적용한다. 외부 음원이나 API를 사용하지 않는다.

강약 버퍼 사이를 선형 보간한다. 킥의 저음 높이는 킷 안에서 안정적으로 유지하고, 스네어와 하이햇은 강약에 따라 밝기와 타격 비율이 달라진다. 탐은 기준 음으로 합성한 뒤 필인 음정에 맞춰 재생한다. 변형 선택은 시드와 반복되는 마디/타격 정체성에서 결정하며 실행 순서에 의존하지 않는다.

`drum-performance.ts`는 v5 악보를 바탕으로 드럼 표현만 더한다. 기본 킥·스네어 백비트, 화음·선율·베이스와 기존 킥 회피 시점을 보존한다. 하이햇은 최대 4ms 뒤로 움직이고, D&B는 더 작은 지연과 짧은 킥을 사용한다. 하우스의 열린 하이햇, D&B의 반열린 하이햇 응답, 낮은 음량의 고스트 스네어를 배치한다. 도입·비움·필인 구간에 고스트 노트를 중첩하지 않는다.

하이햇은 다음 타격에서 기존 소스를 8ms 동안 페이드하고 정리한다. 드럼 킷 교체도 같은 씬의 초크 그룹을 공유한다. 현재 악보의 타격은 시간 순서로 전달되며 같은 시각의 중복 하이햇은 생성하지 않는다.

## 믹스와 압축

v6 드럼은 선율용 긴 리버브/피드백 딜레이를 우회한다. 킥은 중앙에 두고 잔향을 보내지 않는다. 스네어·하이햇·보조 타악기는 서로 다른 양으로 190ms의 짧은 룸을 공유하며, 기존 리버브 슬라이더가 이 양도 조절한다. 리듬 음소거는 이 룸까지 포함한 드럼 전체에 작용한다.

드럼 합계 → 320Hz -1.2dB EQ → 2배 오버샘플링 완만한 포화 → 1.5:1 압축 → 출력 보정 → 기존 마스터링이다. 압축 임계값 -18dB, knee 10dB, attack 15ms(D&B)/22ms, release 85ms/130ms를 사용한다. 드럼 리미터를 추가하지 않는다. 병렬 경로의 lookahead 위상 불일치를 피하도록 직렬의 완만한 압축을 사용한다. 전체 마스터의 기존 EQ·게인·압축·피크 제어 수치는 유지한다.

## 비용과 호환

버퍼는 AudioContext별 WeakMap에서 준비 요청을 합치고 한 번만 만든다. 준비 도중 주기적으로 UI에 실행권을 돌려준다. 모든 킷이 준비된 뒤 재생을 시작하므로 연주 중·킷 변경 중에는 합성하지 않는다. 48kHz에서 버퍼 데이터는 15,978,360바이트이며 이번 데스크톱 검증의 준비 시간은 약 2.4초였다. 높은 샘플레이트에서는 메모리·시간이 증가하며, 최초 준비 이후 재사용한다. 서버 운영 비용과 런타임 음원 다운로드는 없다.

v0.11.1부터 저장·공유한 생성기 v1–v5에도 최신 드럼 음색과 전용 믹스를 적용한다. 악보·생성기 버전·저장 번호는 변경하지 않는다. 킷 선택 기능이 없던 v1/v2는 로파이=테이프, 앰비언트=브러시, 덥=일렉트로로 렌더링하며 화면에도 실제 킷을 표시한다. 기존 타격 강도에서 음색 강약을, 시드·타격 정체성에서 변형을 도출한다. v3 이후 직접 선택한 킷은 유지한다. 일반 실행과 새 흐름/분위기/음색 선택은 v6 편곡을 사용한다.

- `tests/browser/drums.js`: 캐시 요청 중복 방지, 336개 버퍼, 모든 킷의 두 모드, 소스·노드 정리 통과. 열린 하이햇의 측정 꼬리 RMS 0.00095537 → 초크 후 0, 리버브 100의 짧은 잔향 RMS 0.0000005604.
- 30개 코드 진행의 마지막 네 마디를 180BPM·에너지/변화/리버브/볼륨 100으로 렌더링한 최대 샘플 피크 0.85286, 유효하지 않은 샘플과 풀스케일 초과 없음. 여덟 개 단독 킷/모드의 드럼 버스 피크는 0.184 미만.
- 네 킷 × 하우스/D&B 합주를 v5/v6로 비교. v6 최대 출력 피크 0.84005, 최대 마스터 리미터 감쇄 차이는 0.002dB 미만. 이는 동일한 시드·설정의 정해진 오프라인 구간 측정이며 트루 피크나 지각 음질의 보증은 아니다.
- 실시간 브라우저에서 킷 네 종류의 재생 중 변경, 리듬 음소거, 언어 전환, 기본값 복원, v5 공유곡 → 새 흐름 v6 전환, 정지 후 suspend/소스 0 확인. transport 회귀에서 late/clockStalls/error 0.
- 브라우저 DSP와 출력 장치별 청취 차이는 남는다. 전문 제작물과 같은 지각 품질을 자동 테스트만으로 보증하지 않는다.

### v0.11.1 저장곡 적용 검증

`tests/browser/saved-drums.js`로 v1–v5 × 세 분위기의 드럼이 실제로 새 버퍼·버스를 거치는지 확인했다. 드럼이 있는 마디를 골라 렌더링했으며, 최대 샘플 피크 0.85521, 유효하지 않은 샘플 및 종료 후 활성 소스 없음. 기존 이벤트와 생성기 버전은 유지됐다. 실제 저장 목록에서 v1/v5 음악을 불러와 재생·정지한 뒤 시드·설정·저장 JSON·번호가 그대로인지도 확인했다. Node 테스트 42개와 빌드/라이선스 검사를 통과했다.
