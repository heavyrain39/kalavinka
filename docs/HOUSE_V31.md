# 하우스 필터 v31 · 덜 먹먹하게 닫히는 필터 · v0.37.0 / 생성기 v31

"늦은 밤(하우스)에서 필터가 닫힐 때 너무 먹먹하고 멀게 들린다"는 피드백에서 시작했다. v23의 구간별 로우패스는 그대로 두고, 닫히는 깊이와 공명만 바꾼다. 악보는 v30과 한 음도 다르지 않다.

## 1. 진단 (v30)

- **필터:** 음악 버스(화음·멜로디·아르페지오와 리버브·딜레이 꼬리)에 걸리는 12dB/옥타브 로우패스다. 공명은 없다(Q 0.7). 킥·하이햇·베이스는 거치지 않는다.
- **닫히는 깊이:** 인트로는 180Hz에서 시작하고, 브레이크다운은 280Hz에 4마디 머문다. 곡 끝은 250Hz까지 닫힌다.
- **문제:** 하우스 화음의 에너지는 대부분 300–600Hz에 있다. 280Hz 로우패스는 500Hz에서 약 -10dB, 1kHz에서 약 -22dB를 깎는다. 윗배음뿐 아니라 화음의 몸통까지 줄어서, 귀에는 "벽 너머, 멀리서" 나는 소리로 들렸다. 공명이 없어서 필터 색 없이 소리가 사라지는 쪽으로 들렸다.

## 2. 규칙 (`src/house-v23.ts`, `src/audio.ts`)

- **하한:** 열리고 닫히는 마디는 v30과 같고, 닫힌 값만 올린다.

| 구간 | v30 | v31 |
| --- | --- | --- |
| 인트로 (1–7마디) | 180 → 600Hz | 350 → 1000Hz |
| 브레이크다운 | 280Hz | 550Hz |
| 빌드업 | 300 → 1000Hz | 600 → 1600Hz |
| 곡 끝 (31–32마디) | 600 → 250Hz | 900 → 450Hz |

- **공명:** 닫힐수록 차단 주파수 근처를 조금 솟게 한다. Web Audio 로우패스의 Q(공명 dB)를 600Hz 이하에서 4, 2.4kHz 이상에서 0.7(v30과 같음)로 두고, 그 사이는 로그 주파수에 비례해 옮긴다. 마디 안에서는 차단 주파수와 함께 매끄럽게 바뀐다.
- **적용 범위:** 늦은 밤의 포 온 더 플로어 v31에서만 바뀐다. v30 이하 곡은 180·280Hz 흐름과 평평한 필터를 그대로 쓴다. 같은 장면에서 v30 곡으로 넘어가면 공명도 0.7로 돌아간다.

## 3. 결과

ZK9Q, 108 BPM, 전체 믹스를 마디별로 쟀다.

| 구간 | 항목 | v30 | v31 |
| --- | --- | --- | --- |
| 브레이크다운 16–19마디 | 300–600Hz | 53.8dB | 61.6dB |
| | 600Hz–1.2kHz | 27.8dB | 42.4dB |
| | 1.2–4kHz | -10dB 안팎 | -10dB 안팎 |
| 인트로 0–5마디 | 300–600Hz | 54–69dB | 66–72dB |
| 그루브 12–15마디 | 전 대역 | 같음 | 같음 |

- **화음 몸통:** 브레이크다운의 300–600Hz가 8dB, 600Hz–1.2kHz가 14dB 살아났다. 열린 그루브(300–600Hz 63–68dB)보다는 여전히 어둡다.
- **고역:** 1.2kHz 위는 그대로다. 닫힌 구간에 새로 밝아지거나 공명이 휘파람처럼 솟는 일은 없다.
- **음량:** 12–23마디 통합 음량은 -11.8 → -12.0 LUFS로 같다. 분석 도구로 비교하면 v31이 더 밝다(밝기 중심 281 → 357Hz).

## 4. 검증

- **`tests/house-v31.test.ts`:**
  - 네 분위기 악보가 v30과 같다.
  - v30 곡은 기존 흐름과 평평한 필터를 그대로 쓴다.
  - 열리고 닫히는 마디가 v30과 같고, 닫힌 마디는 모두 v30보다 높다. 하한은 350Hz 이상이고, 브레이크다운은 500–650Hz다.
  - 공명은 열린 필터에서 0.7, 닫힌 필터에서 4이고, 필터가 열릴수록 줄어든다.
- **기존 테스트:** v23 흐름 테스트는 생성기 v30으로 고정했다. v30 테스트의 기본 버전 확인을 "30 이상"으로 바꿨다.
- **전체:** 테스트 138개 통과, 빌드와 배포 점검 통과.
- **앱 확인:** 늦은 밤 재생 15초, 콘솔 오류 없음, 정지 정상.

  - `housefilter-intro-before.wav`, `housefilter-intro-after.wav`: ZK9Q 0–8마디(인트로)
