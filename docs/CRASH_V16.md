# 크래시 심벌 · v0.22.0 / 생성기 v16

구절이 넘어갈 때 한 번 치고 길게 퍼지는 크래시 심벌을 추가한다. 기존 하이햇 길이를 늘리는 대신 독립된 음원과 재생 경로를 사용하므로, 다음 하이햇이 닫혀도 크래시의 잔향이 잘리지 않는다.

## 음악 규칙

- 8마디 경계의 첫 박자만 후보로 삼는다. 곡의 맨 처음, 앰비언트, 비움 구간, 에너지 25 미만에서는 넣지 않는다.
- 후보 확률은 일반 전환에서 `0.24 + 에너지 × 0.0012`, 직전 마디에 기존 필인이 있으면 `0.62 + 에너지 × 0.0012`다. 시드·모드·절대 마디로 결정하므로 다시 재생하거나 저장해도 같다.
- 실제로 한 번 울리면 바로 다음 8마디 경계는 쉰다. 마지막 비움 경계부터 짧게 계산하여, 거절된 확률 후보를 실제 타격으로 오인하지 않으면서 임의 위치 재생을 재현한다.
- 네 킷에 맞춰 2.2–3초의 감쇠를 사용한다. 짧은 비정수 배음의 타격이 넓은 노이즈 잔향으로 이어진다. 브러시 킷은 더 부드러운 어택과 어두운 톤을 사용한다.

기존 멜로디·아르페지오·베이스·킥·스네어·하이햇·필인 악보는 바꾸지 않는다. v15 이하 저장곡에는 크래시가 새로 생기지 않는다. `crash`를 저장 악보의 허용 음원에 포함하며 리듬 음소거, 재생 중 정지, 구절 저장·재생에 기존 수명 관리를 적용한다.

## 구현과 검증

긴 크래시는 킷 네 개 × 타격 변형 두 개의 버퍼 8개를 공유한다. 강약은 재생 게인에 적용하고 하우스·D&B 및 세 강약 조회 키는 같은 버퍼를 참조한다. 기존 336개 버퍼는 그대로다. 48kHz에서 실제 버퍼 메모리는 20,048,768바이트이며 조회 항목은 384개다.

Node 테스트 74개, TypeScript·프로덕션 빌드·라이선스 검사를 통과했다. 기존 드럼의 샘플 바이트 지문, v15와의 크래시 제외 악보 동일성, 간헐적 배치·휴식, 저장 악보와 임의 마디 조회를 확인했다.

Chrome에서 180 BPM으로 실제 전환을 지나 재생하고 크래시가 든 구절을 저장·새로고침·불러오기 했다. 정확한 악보 복원, 지연 음표 0, 페이지 오류 0, 잔향 도중 정지 후 활성 음원 0을 확인했다. 별도 오프라인 검사에서 네 킷 모두 하이햇 초크 유무에 따른 크래시 출력 차이는 0이었다. 세 리듬 모드 × 네 킷의 최대 설정 전체 믹스 렌더 12개는 모두 유한했고 피크는 0.858 미만, 완료 뒤 남은 음원·정리 콜백은 0이었다. 테스트 파일은 `tests/browser/crash.js`, `crash-render.js`, `drums.js`다.

일반·필인 전환 확률은 실제 전체 타격 비율과 다르다. 비움 구간 제외와 타격 뒤 한 경계 휴식이 추가로 적용된다. 청취 인상은 기기와 믹스에 따라 달라지며, 신호 검사는 미적 품질의 평가를 대신하지 않는다.
