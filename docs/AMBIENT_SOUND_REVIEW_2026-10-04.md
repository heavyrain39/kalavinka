# 고요한 공간 — 음질·감쇠 조사와 개선 제안

조사일: 2026-10-04. 대상: v0.18.0, generator 12, `e9b77cbdc2cb2e41fd5947391b92d8cc0efe53d9`.

## 결론

가장 먼저 개선할 것은 앰비언트의 음 종료 방식과 화음 연결이다. 현재의 짧은 악기 release, 반복되는 화음 전체 재발음, 단순한 잔향 구조는 사용자가 말한 인위적인 인상을 설명하는 유력한 후보다. 리버브 양만 늘려 해결하려 하지 말고, 좋은 원음과 자연스러운 감쇠를 먼저 만들고 그 뒤 공간을 설계하는 순서를 권한다.

이번 작업은 코드 조사, 48 kHz Web Audio 렌더 측정, 외부 기술 자료 조사와 제안이다. 청감 선호의 확정이나 개선판 배포 결과가 아니다. 제작자 자료와 별도 코드 검토를 참고했지만, 아래의 청감 영향은 검증된 코드 사실과 구별한다.

### 감쇠 측정

48 kHz OfflineAudioContext에서 현재 합성기와 room 함수를 그대로 사용했다. IR을 통과한 단일 임펄스의 역방향 적분 에너지 곡선은 -20 dB에 약 0.847초, -40 dB에 1.316초, -60 dB에 1.579초에 도달했다. 리버브 28/76에서 이 시간은 같다. 이는 이 유한 IR의 직접 측정값이며, 실제 공간에서 회귀로 추정한 RT60과 동일한 측정 절차라고 주장하지 않는다.

별도의 단음 probe에서 벨 아르페지오는 note-off 이후 20–40 ms 구간 RMS가 종료 직전 50 ms RMS보다 약 54.8 dB 낮았다. 따라서 단순히 설정 숫자만 짧은 것이 아니라 실제 dry 음도 빠르게 사라진다. 이 결과는 probe의 음고·gain에 해당하며 전 음역의 동일한 dB 값을 뜻하지 않는다. 모든 probe의 source는 종료 후 정리됐다.

현재 마스터에는 drive 3.2배와 compressor/limiter가 있지만, 이것만으로 과압축이 원인이라고 판정할 수 없다. 실제 gain reduction과 음량을 맞춘 비교가 필요하다.

## 권장 개선 순서

### 1. 앰비언트에 맞는 음 종료와 화음 연결

- note gate와 악기의 물리적인 울림을 분리한다. 벨·마림바는 짧게 타격해도 여운이 자연스럽게 남도록 하고, 플루트·패드는 지속음에 맞는 호흡을 준다.
- 같은 화음 또는 공통음은 불필요한 재발음을 줄여 유지한다. 다른 음으로 바뀌는 성부만 천천히 연결한다. 모든 화음 꼬리를 무차별로 겹치지 않는다.
- 제안하는 초기 A/B 범위는 패드 attack 0.6–1.5초, release 1.2–2.5초, 벨의 느린 잔향 0.6–1.4초다. 확정값이나 보편적 정답이 아니며 음역·감쇠곡선·화음 전환에 따라 조정한다. 공통음이 아닌 이전 화음의 음은 더 빨리 정리한다.
- 아르페지오의 1–4/5–8/3–8마디 출입과 일정한 시계는 유지한다. 음마다 큰 타이밍 오차를 넣기보다 발음·밝기·감쇠를 다듬는다.
- 프로필 첫 선택과 기본값 버튼의 공간량 정책을 일치시키되, 사용자가 직접 조절한 값의 보존도 고려한다.

예상 효과: 뚝 끊기는 음과 주기적으로 재시작하는 화음이 줄어든다. 위험: 성부 수와 저중역 누적 증가. 따라서 동시 발음 상한, 잔향 정리, 전환부의 불협화음을 함께 확인한다.

### 2. 소수의 좋은 음색부터 완성

패드 한 종류와 타격음 한 종류를 먼저 충분히 다듬는 것이 모든 악기에 노이즈나 detune을 추가하는 것보다 낫다. 패드는 독립적이고 느린 작은 음색 변화, 넓되 과하지 않은 스테레오, 음역별 밝기·배음 균형을 설계한다. 벨·마림바는 partial별 다른 감쇠와 타격 강도 반응을 다듬는다.

실제 피아노·플루트의 자연스러움까지 목표라면 작은 멀티샘플 세트가 개발 대비 효과적인 후보다. 패드·베이스는 합성을 유지하고 전면 악기에만 샘플을 쓰는 혼합 구성을 권한다. 순수 합성만으로도 아름다운 앰비언트는 가능하지만, 현재 몇 개의 oscillator로 실제 악기의 세부를 재현하려는 접근에는 한계가 있다.

Versilian Studios의 VSCO 2 CE는 제작사에서 CC0와 원본 WAV 배포를 명시한 검토 가능한 후보다. 특정 피아노·플루트의 최종 음질을 검증한 것은 아니다. 전체 3 GB를 앱에 넣기보다 필요한 음역·강도·반복 변이만 선별하고, 초기 로딩·디코딩 메모리·모바일 동작을 비교한다. 샘플 사용은 서버 생성이나 외부 API를 필요로 하지 않는다.

### 3. 공간의 질 개선

현재 ConvolverNode를 유지하면서 잘 고른 IR로 비교하는 것이 가장 작은 첫 실험이다. 비교 후보는 자연스러운 초기반사가 있는 약 2초 공간과 부드러운 4–6초 홀이다. 길이만으로 품질을 판단하지 않는다. 베이스에는 적게, 타격음에는 더, 패드에는 적절한 양을 보내도록 파트별 send를 나눈다.

그 다음 후보는 약한 modulation과 주파수별 감쇠를 갖춘 알고리즘 리버브다. 높은 음이 먼저 가라앉고 중역의 꼬리가 매끄럽게 남도록 설계한다. 저역의 과도한 누적과 노골적인 chorus/피치 흔들림은 피한다. 시간에 따라 변화하는 공간이 실제로 더 좋다는 비교 결과가 나오면 FDN 등으로 발전시킨다. 컨볼루션 방식 자체가 현재의 문제라는 뜻은 아니다.

긴 tail을 채택하면 새 흐름 전환의 기존 0.65초 fade/0.9초 dispose 정책도 함께 검토해야 한다. 정지 버튼의 빠른 정지 의도와 곡 전환의 자연스러운 잔향 처리는 구별한다.

### 4. 같은 음량의 비교로 선택

고정 seed와 같은 60초 악보로 A=현재, B=감쇠·화음 연결만 개선, C=B+새 공간을 만든다. 샘플 음색은 별도 D로 비교한다. 평균 음량을 맞춰 ‘더 큼’을 ‘더 좋음’으로 오인하지 않게 한다.

평가 항목은 자연스러운 끝맺음, 화음 전환, 오래 들을 때의 피로, 멜로디 식별, 저역의 탁함이다. 실제 청취와 함께 모바일 음 끊김, active sources, 장시간 CPU, 저장곡 재현을 확인한다. 마스터링 변화는 이 비교 뒤에 결정한다.
