# v0.10.0 — 클릭 잡음 완화와 화면 언어

## 오디오

짧은 지속음의 감쇠 끝과 유지 구간 끝이 같을 때 서로 다른 지수 램프 목표를 같은 시각에 예약했다. Chromium 48kHz OfflineAudioContext에서 상수 신호에 기존 엔벌로프를 적용하자 경계 ±1ms의 최대 인접 샘플 차이가 0.0360448로 재현됐다. 짧은 음에는 목표를 하나만 예약하도록 수정한 뒤 같은 측정은 0.000534862였다. 이는 격리된 음량 엔벌로프 측정이며 전체 음악의 잡음 크기를 뜻하지 않는다.

베이스는 절대값 1e-6까지 급격히 감쇠하는 대신 현재 음량 대비 0.001까지 기존 55ms 안에서 감쇠하고, 다음 5ms 동안 정확한 0까지 선형 페이드한다. 테스트 신호에서 릴리스 20ms 후 음량은 시작의 8.11%였다. 음표 시각·게이트·완전 무음 시각은 유지한다. 이전 음색 경로의 마지막 0 전환도 선형 페이드로 바꿨다. 타악기 고유의 어택과 마스터링 게인은 유지했다.

사용자가 들은 소리의 녹음은 없으므로 이 원인만으로 모든 기기의 클릭이 해결됐다고 단정하지 않는다. 재현된 음량 단차를 제거하고 종료부를 완화한 변경이다.

## UI

- KO/EN은 페이지 안의 문구, 음색 옵션, 도움말, 저장 목록, 토스트, 앱 정보, 접근성 레이블과 미디어 메타데이터를 함께 바꾼다. 기존 영문 워드마크→한국어 호버 동작은 유지한다.
- 매 로드 시 `navigator.language`가 `ko` 또는 `ko-*`이면 한국어, 나머지는 영어다. 수동 전환은 현재 페이지에만 적용한다. 음악 설정·공유 링크에 언어를 섞지 않는다.
- 기본값은 템포·에너지·온기·변화·리버브·볼륨만 복원한다. D&B는 170 BPM, 고요한 공간은 리버브 76%, 나머지는 28%, 볼륨은 55%다. 시드·음색·레이어·생성기 버전·타이머는 유지한다.

## 검증 (2026-10-03)

- Node 테스트 40개 통과. 이전 생성 규칙의 26,737개 이벤트 비교 포함. 프로덕션 빌드와 배포 구성요소·라이선스 검사 통과.
- `tests/browser/declick.js`: 짧은 지속음, 베이스 종료 시각, 겹친 덕킹, 일곱 음색의 유효 신호와 소스 해제 확인. 덕킹 경계 최대 샘플 차이 0.000422776.
- `tests/browser/timbre.js`: 여덟 음색의 감쇠·잔향·재현성, 베이스 쉼표, 리버브 0/100 확인.
- `tests/browser/harmony.js`: 30개 진행의 마지막 네 마디를 180 BPM·에너지/변화/리버브/볼륨 100으로 렌더링. 최대 샘플 피크 0.875994, NaN/Infinity 및 풀스케일 초과 없음. 타악기 여덟 조합도 통과. 인증된 트루 피크 측정은 아니다.
- `tests/browser/transport.js`: 템포 연속 변경, 재생/정지·재생성 경합, 타이머 종료·소스 해제 통과. 측정 중 late/clockStalls/error 0.
- `tests/browser/localization.js`: ko-KR/en-US/ja-JP 초기 언어, 재생 중 전환 시 음악 설정 유지, 번역 누락, D&B 복원, 재로드 언어 확인. KO/EN 각각 1440×900·1366×768에서 스크롤 없음, 390×844·320×740에서 수평 넘침 없음. 앱 정보 팝업과 실제 스크린샷 확인.
