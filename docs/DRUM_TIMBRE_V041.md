# 드럼 음색 · 스네어와 하이햇을 다시 만듦 · v0.41.0

스네어, 킥, 하이햇 음색을 점검하고 어색한 두 가지를 고쳤다. 스네어는 일정한 음높이의 "삑" 소리가 대부분이었고, 열린·반열린 하이햇은 트라이앵글처럼 울렸다. 킥은 그대로 두었다.

음색은 생성기 버전에 묶이지 않는다. 악보는 한 음도 바뀌지 않고 생성기 버전도 v33 그대로이며, 저장한 곡과 공유 링크도 새 소리로 재생된다(v0.11.2의 킥 변경과 같은 방식).

## 1. 진단 (v0.40)

네 킷 × 하우스/D&B × 세 강약의 원샷을 따로 렌더링해 스펙트럼, 감쇠 시간, 음량(K 가중)을 재고, 소리 분류 모델(earshot: CLAP 태그, AudioSet 라벨)에 무엇처럼 들리는지 물었다.

- **킥:** 문제없다. "킥 드럼"으로 강하게 읽히고(z +4.9) 낮은 기음, 빠른 펀치, 클릭이 균형 잡혀 있다. 손대지 않았다.
- **스네어:** 통 울림이 171–193 Hz의 일정한 사인파 하나였고, 이 선 하나가 전체 에너지의 53–80%를 차지했다. 와이어(노이즈)는 통 울림보다 3–13 dB 작았다. 분류 모델은 스네어로 읽으면서도 "싸구려 합성 비프음"(z 2.4–3.0), "칩튠 블립"을 함께 붙였다.
  - 강약이 음색을 거의 바꾸지 않았다(약한 타격의 밝기가 센 타격의 98%).
  - 일렉트로와 미니멀, 브러시와 테이프 스네어가 서로 거의 같았다.
- **열린·반열린 하이햇(테이프·일렉트로·미니멀):** 사인파 부분음 몇 개(8.9·12·13.4 kHz 등)가 감쇠 내내 울렸다. 꼬리 에너지의 4.5–9%가 한 줄에 몰려 있었고, 분류 모델은 "트라이앵글"(z 3.2–3.5, 강함), AudioSet은 Clang 0.6 / Ding 0.3–0.4를 붙였다. 브러시 킷은 노이즈 위주라 괜찮았다.

## 2. 바꾼 것 (`src/drum-bank.ts`)

### 스네어

- **통 울림:** 두 모드(기음과 1.76배)가 타격 순간 높게 시작해 약 11 ms 안에 제 음으로 내려온다(일렉트로 +14%, 나머지 +24%). 울림은 22–40 ms로 짧다. 일정한 사인파가 아니라 맞은 막처럼 들리게 하려는 것이다.
- **와이어:** 2극 하이패스 노이즈에 와이어가 실제로 울리는 대역(킷에 따라 2.1–4.8 kHz)을 더했다. 통 울림과 비슷하거나 조금 큰 수준이다.
- **강약:** 약한 타격은 노이즈의 고역이 닫혀 더 어둡다. 크랙도 강약을 더 크게 따른다.
- **킷마다 다른 스네어:**

| 킷 | 기음 | 통 울림 | 와이어 감쇠 (하우스 / D&B) | 성격 |
| --- | --- | --- | --- | --- |
| 브러시 | 172 Hz | 32 ms | 62 / 52 ms | 느린 어택, 부드럽고 긴 와이어 |
| 테이프 | 190 Hz | 30 ms | 50 / 40 ms | 중역 와이어, 작은 클랩 질감 |
| 일렉트로 | 186 Hz | 40 ms | 45 / 38 ms | 통 울림이 가장 크고 포화가 강함 |
| 미니멀 | 206 Hz | 22 ms | 27 / 24 ms | 짧고 밝고 건조함 |

### 하이햇

- **몸통:** 사인파 부분음을 없앴다. 노이즈를 일곱 개의 비정수 공명(3.3–14 kHz, Q 9)에 통과시켜 금속 색을 낸다. 공명마다 폭이 수백 Hz라 어느 한 줄도 음높이로 들리지 않는다.
- **공기:** 공명 소리에 넓은 노이즈를 킷 비율대로 섞는다. 브러시는 공기가 많고 미니멀은 금속이 많다.
- **스틱:** 처음 4 ms에만 사각파 여섯 개(대역 제한)가 타격음을 낸다.
- **강약:** 약한 타격은 고역이 닫힌다.
- **음량:** 하우스 기준으로 예전보다 0.4–1.7 dB 크다. 예전 하이햇이 믹스에서 꽤 작았기 때문이다.

### 그대로인 것

킥, 림, 탐, 크래시는 샘플 단위로 예전과 같다. 닫힌·반열린·열린 하이햇의 감쇠 시간, 드럼 버스(보이스 게인, 하이패스, 글루, 룸)와 악보도 그대로다.

## 3. 결과

### 스네어 (하우스, 센 타격)

| 킷 | 와이어 − 통 울림 | 가장 센 선 하나의 비중 | 약한 타격의 밝기 | 음량 (K 가중) |
| --- | --- | --- | --- | --- |
| 브러시 | −3.2 → +4.9 dB | 53% → 17% | 98% → 81% | −26.9 → −26.7 dB |
| 테이프 | −7.6 → +4.3 dB | 70% → 19% | 98% → 76% | −27.0 → −26.0 dB |
| 일렉트로 | −6.8 → +0.4 dB | 67% → 39% | 98% → 60% | −24.7 → −24.0 dB |
| 미니멀 | −6.5 → +5.6 dB | 64% → 14% | 98% → 66% | −26.4 → −26.8 dB |

- "싸구려 합성 비프음" 순위: 예전 스네어 8개가 위를 모두 차지한다(z 2.4–3.0). 새 스네어는 모두 2.2 이하다.
- "스네어 타격" 태그: 브러시 6.4 → 6.8, 일렉트로 5.8 → 6.3.
- 첫 시도는 통 울림이 와이어보다 10–19 dB 작아 노이즈 덩어리에 가까웠다. 무게가 빠지는 쪽도 어색하므로 위 표의 비율로 다시 맞췄다.

### 하이햇 (하우스, 센 타격)

| 킷 | 열린 하이햇 꼬리에서 가장 센 선 | 음량 닫힘 / 반열림 / 열림 (K 가중, 예전 → 지금) |
| --- | --- | --- |
| 브러시 | 1.3% → 1.7% | −40.6 / −37.2 / −33.2 → −39.8 / −36.1 / −31.5 dB |
| 테이프 | 9.1% → 2.2% | −45.9 / −41.9 / −37.9 → −44.7 / −40.4 / −36.8 dB |
| 일렉트로 | 6.6% → 1.6% | −43.7 / −39.5 / −35.4 → −42.7 / −38.6 / −34.3 dB |
| 미니멀 | 4.5% → 1.3% | −43.6 / −39.6 / −35.6 → −43.2 / −39.1 / −35.0 dB |

- "트라이앵글이나 작은 종" 순위: 위 12개가 모두 예전 하이햇이다. 테이프 열린 하이햇의 트라이앵글 태그는 z 3.5(강함) → 1.9(해당 없음), 일렉트로는 3.2 → 2.1이다. AudioSet의 Clang·Ding 라벨은 사라졌다.
- "하이햇" 태그(열린 하이햇): 테이프 5.7 → 6.1, 일렉트로 5.6 → 6.2.
- 밝기(스펙트럼 중심): 브러시 약 6.4 kHz, 테이프 6.7–7.1 kHz, 일렉트로 9.2–9.5 kHz, 미니멀 9.4–9.7 kHz. 예전과 0.2–1 kHz 안쪽으로 차이 난다.

### 준비 시간

드럼 버퍼 336개(크래시 제외) 합성이 Node에서 2.0초 → 2.1초다.

### 귀로 확인하지 않은 것

이 변경은 측정과 분류 모델로 판단했고 사람 귀로 듣고 정한 것이 아니다. 원샷 단위로 쟀으므로 실제 믹스 안에서 스네어의 무게, 하이햇의 크기가 알맞은지는 들어 보고 조정할 여지가 있다.

## 4. 검증

- **`tests/drum-timbre.test.ts`** (새 테스트 5개. 예전 소리에서는 5개 모두 실패한다.)
  - 스네어: 한 줄이 에너지의 45%를 넘지 않고, 와이어와 통 울림의 비가 −1.5 dB에서 +9 dB 사이다.
  - 약한 스네어는 센 스네어보다 10% 넘게 어둡다.
  - 미니멀 스네어는 일렉트로보다 밝고 짧으며, 브러시 스네어는 미니멀보다 길다.
  - 열린 하이햇 꼬리에서 가장 센 선이 4.2%(반열림 7%)를 넘지 않는다. 모든 킷·강약·변형에서 확인한다.
  - 하이햇 음량이 스네어의 12–50%(RMS) 안에 있고, 약한 타격이 더 어둡고, 중심이 5 kHz 위에 있으며 킷마다 밝기가 다르다.
- **`tests/crash.test.ts`:** 킥·림·탐은 샘플 단위로 그대로다(해시 고정).
- **`tests/drums.test.ts`:** 모든 버퍼가 유한하고, 피크 1 미만, DC 0.0003 미만, 끝이 조용하고, 다시 만들어도 같다.
- **앱:** 드럼 뱅크 384개가 준비되고 재생에서 늦은 음과 오류가 없다.
- **전체:** 테스트 164개 통과, 빌드와 배포 점검 통과.
