# 베이스 합주 개선 · v0.21.0 / 생성기 v15

기존 베이스는 네 마디 리프 중심이었고 전자 계열에서는 킥과의 근접을 일괄 회피했다. v15는 기존 멜로디를 보존한 상태에서 베이스를 여덟 마디 단위로 다시 계획한다. 멜로디 반복성 약을 포함한 기존 선택은 업그레이드와 새 흐름에서도 유지한다.

## 편곡

- 여덟 리듬 계열에서 제시·응답·지지·마무리 후보를 만든다. 킥에 맞춘 지지 음과 멜로디 사이에 들어가는 응답을 함께 평가한다. 일반 모드는 32마디, 앰비언트는 64마디 단위로 리듬 계열을 순환한다.
- 근음·3도·5도와 가까운 옥타브 중 멜로디와의 겹침, 직전 음과의 거리, 다음 화음의 근음을 고려해 경로를 선택한다. 주요 지지 음은 근음을 우선하되 멜로디와 부딪히면 5도도 허용한다. 비슷한 점수의 후보 사이에서는 시드에 따라 선택한다.
- 따뜻한 책상과 늦은 밤의 일반 리듬에서는 일부 구간에 킥 반 박자 뒤의 낮은 근음 반복을 넣는다. MIDI 34–45의 근음을 유지하고 화음이 바뀌면 따라간다. 에너지 25 이상, 비움 구간 제외, 시드와 32마디 구간으로 정한 약 1/3의 후보 구간에서 검토한다. 지속되는 멜로디와의 거친 음정 겹침이 많으면 응답형으로 돌아간다. D&B와 앰비언트에는 이 반복형을 적용하지 않는다.
- 반복형의 긴 음은 다음 킥을 지나도록 유지할 수 있어 기존 킥 덕킹을 함께 사용한다. 새 사이드체인 강도 조절을 추가한 것은 아니며, 실제 덕킹 깊이는 종전 프로필·구간 규칙을 따른다.
- 앰비언트는 화음 지지와 소수의 긴 응답만 사용한다. 짧고 촘촘한 리듬을 강제하지 않는다. 저음 릴리스 여유 70ms를 예약하여 다음 베이스 음 및 화음 경계 전에 끝낸다.

화성·드럼·멜로디·아르페지오는 동일 설정의 v14와 같은 악보를 유지한다. 음소거는 완성된 악보에서 해당 파트만 제거하므로 다른 파트를 바꾸지 않는다. 과거 버전 저장곡과 공유 링크는 종전 생성기를 사용한다. 시간 누적 상태 없이 임의 마디 조회, 캐시 퇴거, 저장한 여덟 마디 재생을 재현한다.

## 검증

Node 테스트 71개와 TypeScript·프로덕션 빌드·라이선스 검사를 통과했다. v14 네 모드의 지문, 반복성 네 단계의 다른 파트 보존, 템포 양끝의 단음 게이트, 코드톤, 시드별 다양성, 재현·저장·음소거를 검사했다. 별도 144개 구간 코퍼스에서는 킥 뒤 근음 반복과 응답형이 모두 선택되고, 실제 덕킹 킥을 가로지르는 긴 음이 나오는지 확인했다.

16개 시드 × 64마디 × 네 모드의 고정 코퍼스에서 7반음 초과 베이스 도약은 v14의 742회에서 v15의 23회로 줄었다. 킥과 15–85ms 사이로 어긋난 베이스 진입은 0회였다. 거친 음정의 단순 겹침 비율은 일부 모드에서 오히려 소폭 증가했으므로, 충돌 완전 제거 또는 청취 품질 향상의 객관적 증명으로 해석하지 않는다. 이 지표는 음색·배음·실제 릴리스·청감 전체를 표현하지 않는다.

Chrome에서 네 모드를 180 BPM으로 여덟 마디 이상 재생하고 저장·새로고침·불러오기를 확인했다. 예약 지연과 페이지 오류는 0, 정지 뒤 활성 음원은 0이었다. 두 시드 × 네 모드 × 네 베이스 음색의 32회 전체 믹스 렌더는 에너지·변화·리버브·볼륨을 최대로 두고 검사했다. 모든 샘플이 유한하고 최대 피크는 0.854 미만이었으며 렌더 완료 뒤 음원과 정리 콜백이 남지 않았다.

브라우저 실행 및 렌더 검사는 `tests/browser/bass.js`, `tests/browser/bass-render.js`로 재현한다. 전후 비교는 같은 PULSE2 시드, 늦은 밤, 108 BPM, 반복성 약, 9–24번째 마디의 전체 믹스를 사용하며 평균 RMS 0.08로 맞춘 43초 WAV를 로컬 `output/playwright/bass-before.wav`, `bass-after.wav`에 보관한다. 비교 파일은 배포물에 포함하지 않는다.
