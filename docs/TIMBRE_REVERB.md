# v0.7.0 — 악기 감쇠와 리버브

## 적용한 소리 개선

기존 팔레트의 공통 ADSR은 공격 직후 정해진 sustain으로 내려간 뒤 음표 종료까지 거의 일정했다. 건반·벨·마림바·플럭도 비슷하게 유지되어 음색과 길이가 기계적으로 들릴 수 있었다.

- 타격 계열은 음표가 유지되는 동안에도 연속 감쇠한다. 높은 배음은 별도 gain으로 더 빨리 사라진다. 건반은 살짝 어긋난 배음, 벨·마림바는 고유 배음비를 사용한다.
- 작은 해머·피킹 노이즈와 플루트의 대역 제한 숨소리, 늦게 들어오는 비브라토를 추가했다. 패드·오르간의 흔들림은 더 작다.
- 음표 위치·음높이로 결정되는 미세 음색 변화를 쓰며, 매번 무작위 튜닝이나 음표 변경은 하지 않는다. 기존 gain의 악기별 기준 비율을 밝기 변화에 사용한다. 이는 독립적인 연주 velocity 데이터의 대용이다.
- 릴리스는 악기별 .055–.58초이며, 베이스는 .055초+정리 시간으로 기존 .065초 릴리스와 .015초 정리 시간 안에 머무른다. 기존 베이스 간격·덕킹·음표 생성 규칙을 유지한다. 음표 끝은 댐퍼 역할을 하며 무한히 겹치는 자유 울림은 만들지 않는다.
- 음량 0/음표 없는 잘못된 이벤트는 노드를 만들지 않는다. 예정된 종료 뒤 음원과 노드를 정리한다.

실제 녹음 샘플을 사용한 것은 아니다. 실제 악기의 고유한 공명·주법·어택 변화를 더 높이는 다음 단계는 **음역별·강약별 멀티샘플 + 같은 음의 교대 샘플 + 릴리스 샘플**이다. 건반·브러시·플루트부터 선택한 악기의 파일만 정적으로 지연 로드하고 캐시하는 구성이 적합하다. 이 경우에도 서버/API는 필요 없지만, 샘플 재배포 라이선스 확인과 초기 다운로드·메모리 비용이 생긴다. 이번 릴리스에는 외부 음원/의존성 추가가 없다.

## 리버브

기존 로컬 스테레오 임펄스를 재사용하며, 220Hz 고역통과 → 18ms 프리딜레이 → 컨볼루션 → 3400Hz 저역통과 → wet gain으로 구성한다. 0–100은 잔향 양이며 방 크기/잔향 시간은 고정이다. 0이면 이 잔향 경로는 무음이며 별도의 리듬 딜레이는 유지된다. Dry 신호는 슬라이더에 따라 변하지 않는다. 120ms 램프로 변경해 노이즈를 줄인다.

기본값은 28, 리버브 필드가 없는 기존 ambient 설정은 76이다. 선택한 값을 분위기 변경·새 흐름에도 유지하고 즐겨찾기/공유 링크에도 보관한다. 리버브만 바꿀 때는 패턴 변경을 예약하지 않는다. 비동기 재생 시작/곡 교체 직후에도 최신 슬라이더 값을 적용한다.

API 근거: [ConvolverNode](https://developer.mozilla.org/en-US/docs/Web/API/ConvolverNode), [AudioParam.setTargetAtTime](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/setTargetAtTime).

## UI

분위기 버튼의 hover 배경·테두리 색 변경을 제거했다. SVG만 1.15초 주기로 98–110% 크기, 최대 ±6도 회전한다. 선택 배경은 선택 상태로만 유지한다. 키보드 포커스에서도 같은 애니메이션이며 reduced motion에서는 움직이지 않는다. 여섯 슬라이더를 위해 짧은 데스크탑과 모바일은 두 열로 배치한다.

## 검증

- 16개 음색 직접 렌더와 4개 스타일 × 4개 팔레트 합주 렌더: 유한한 출력, 피크 <.88 (최대 볼륨·에너지). 추가로 리버브·볼륨·에너지 100에서 같은 16개 조합을 16마디씩 렌더한 결과 최대 피크 .870, 비정상 샘플 0이었다.
- 48kHz OfflineAudioContext에서 감쇠/릴리스, 베이스 잔여 신호, 종료 후 source 해제를 확인했다. 펠트 건반의 고역/기본음 에너지 비율은 .0584→.0253으로 감소했다. 같은 이벤트 반복 렌더 오차 <1.2e-8, 다른 온셋의 미세 변화 존재.
- 리버브 0/100의 원신호 첫 샘플이 같고, 0의 잔향 RMS=0, 100의 잔향 RMS=.000288(단일 임펄스 시험). 실시간 0/100/37 변경에서 패턴 pending=false 및 정상 wet 값 확인.
- 리버브 새로고침·공유 복원, 정지 후 activeSources=0, JS 오류 없음.
- Chrome 1440×900, 1366×840/768, 1280×720, 1024×600 데스크탑과 768×1000, 390×844, 320×720에서 넘침/패널 겹침 없음. Hover 전후 배경·모든 테두리 색 동일, SVG 변형값만 변화.
- 외부 녹음과의 청감 블라인드 비교나 장시간 전 기기 청취를 완료했다는 의미는 아니다.
