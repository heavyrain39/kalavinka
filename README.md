# WORKSONG

당신의 속도로 흐르는 음악. 로그인 없이 브라우저 안에서 음악을 생성하는 무료 노동요 프로토타입입니다.

**실행:** https://heavyrain39.github.io/worksong/

## 사용법

1. Warm desk / Quiet space / After hours 중 분위기를 고릅니다.
2. 재생을 누르고, 템포·에너지·온기·변화를 조절합니다.
3. 화음·베이스·리듬·멜로디를 켜거나 끕니다.
4. 새 흐름으로 다른 구성을 생성하고, 하트 버튼으로 저장하거나 링크를 복사합니다.

설정과 저장한 흐름은 브라우저의 로컬 저장소에만 보관됩니다. 음악 설정 변경은 다음 마디에 반영되고, 볼륨·음소거는 짧은 페이드로 적용됩니다. 집중 타이머는 재생을 시작할 때부터 시간을 셉니다. 재생 탭을 열어둔 상태로 다른 탭에서 작업할 수 있습니다.

## 설계

- **편곡 v2:** 로파이·덥은 32마디, 앰비언트는 64마디 단위로 도입·그루브·비움·복귀를 구성합니다. 4마디 프레이즈의 음수·음높이·쉼표·리듬을 바꾸고, 약박의 경과음은 코드톤으로 해결합니다.
- **장르별 저음:** 로파이는 근음·3음·5음과 다음 화음으로 이어지는 접근음을, 덥은 킥 사이의 엇박 베이스와 킥에 맞춘 베이스 버스 덕킹을, 앰비언트는 긴 근음·5음을 사용합니다. 비트가 없는 구간에는 덕킹도 없습니다.
- **화면:** 큰 소개 영역과 반복 부제, 악기별 가짜 미터를 제거했습니다. 데스크탑은 한 화면에 조작부를 배치하며, 필요한 설명만 마우스·키보드·터치 도움말로 표시합니다. 중앙 파형은 실제 전체 출력을 보여줍니다.
- **백엔드 없음:** GitHub Pages에 정적 HTML·JS·CSS·폰트·오디오 클록 파일만 배포합니다.
- **런타임 API 없음:** 로그인, 데이터베이스, 모델 호출, 분석 추적, 외부 음원 다운로드가 없습니다.
- **Strudel:** `@strudel/core`의 Pattern / Hap / TimeSpan / Cyclist를 사용해 음악 이벤트와 시간을 처리합니다. REPL·코드 평가 기능은 사용하지 않습니다.
- **Web Audio:** FM 건반, 패드, 저음, 노이즈 타악기를 직접 합성합니다. 잔향과 딜레이도 로컬에서 생성합니다.
- **타이밍:** 정적 AudioWorklet 클록이 스케줄러를 깨우고, AudioContext 시간으로 미리 음을 예약합니다.
- **정지:** 소리를 페이드아웃하고 음원을 정리한 뒤 AudioContext를 suspend합니다.
- **재현:** 같은 생성기 버전·시드·설정으로 같은 음표·리듬·화음·타이밍 규칙을 재현합니다. 실제 출력은 브라우저 DSP와 샘플레이트에 따라 조금 다를 수 있습니다.

일반 실행은 새 편곡 규칙을 사용합니다. 기존에 저장한 음악과 공유 링크는 고정된 v1 생성기로 재생하며, 새 흐름·분위기 선택부터 v2를 사용합니다.

제로 오버헤드는 서버 운영·API 요금·런타임 외부 의존성이 없다는 의미입니다. 브라우저 오디오 처리는 사용자의 CPU를 사용합니다. 기기 절전, 브라우저의 메모리 회수, 출력 장치 변경에 따른 중단 가능성은 남아 있습니다.

## 개발

Node.js 24 권장.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 빌드를 실행하고 Pages에 배포합니다. `base: './'` 설정으로 저장소 하위 경로에서 실행됩니다.

## 프로토타입 범위

세 가지 합성음 프로필, 네 레이어, 시드 생성, 설정 저장, 최대 12개의 즐겨찾기, 공유 링크, 25/50분 타이머, 집중 화면, 밝음·어두움·시스템 테마를 제공합니다.

현재 버전은 4/4, 제한된 코드 진행, 정해진 악기 조합을 사용합니다. 보컬, 음원 파일 내보내기, 크롬 웹스토어 배포, 계정 간 동기화는 후속 범위입니다. 장시간 청취 품질과 여러 기기의 백그라운드 안정성은 계속 검토할 영역입니다.
