# Kalavinka · 가릉빈가

당신의 속도로 흐르는 음악. 로그인 없이 브라우저 안에서 음악을 생성하는 무료 노동요 프로토타입입니다.

**실행:** https://heavyrain39.github.io/kalavinka/

## 사용법

1. 따뜻한 책상 / 고요한 공간 / 늦은 밤 중 분위기를 고릅니다. 영어에서는 Warm desk / Quiet space / After hours로 표시합니다.
2. 재생을 누르고, 템포·에너지·온기·변화·리버브를 조절합니다.
3. 화음·베이스·리듬·멜로디를 켜거나 끄고, 각 드롭다운에서 음색을 고릅니다. 같은 악기 영역의 아르페지오도 별도로 켜거나 끄고, 벨·마림바·소프트 플루트·플럭 중 음색을 고를 수 있습니다.
4. After hours의 리듬 메뉴에서 Four on the floor / Drum & bass를 고릅니다. D&B는 170 BPM으로 시작하며 템포를 직접 조절할 수 있습니다.
5. 새 흐름으로 다섯 음색과 곡 구성을 함께 바꾸고, 하트 버튼으로 현재 8마디 구절을 저장하거나, 링크 버튼으로 음악 설정을 공유합니다.

v0.17.0의 아르페지오는 4마디 연주·4마디 쉼으로 더 자주 등장합니다. 앰비언트와 D&B는 8마디씩이며, 첫 등장은 세 번째 마디입니다. 새 흐름의 멜로디와 아르페지오는 서로 다른 음색으로 시작합니다. 다섯 파트 버튼의 배경은 실제 소리에 맞춰 은은하게 밝아지며, 사각 스위치는 켜짐·꺼짐 상태를 표시합니다.

v0.15.0부터 새 곡의 아르페지오는 3마디째 처음 등장하고, 이후에는 쉬었다가 다른 패턴으로 돌아옵니다. 배경 반주가 묻히지 않도록 아르페지오 믹스 레벨도 약 7 dB 높였습니다.

하트는 현재 재생 위치가 속한 8마디 구절(1–8, 9–16, …)의 실제 음표·리듬·코드·아르페지오와 설정을 저장합니다. 구절 중간에 저장해도 불러올 때는 그 구절의 처음부터 같은 멜로디로 시작하며, 8마디 뒤에는 원래 흐름의 다음 구간으로 이어집니다. 현재 구절 안에서 이미 반영된 설정 변경과 예약된 다음 마디도 악보에 보관합니다. 음원 녹음이나 리버브 상태·슬라이더 자동화 녹음은 아닙니다.

다음 8마디로 넘어가면 하트가 다시 비워지고 같은 분위기도 다른 번호로 저장할 수 있습니다. 번호는 분위기별로 `(1)`, `(2)`처럼 붙으며 삭제한 번호를 재사용하지 않습니다. 기존 설정만 저장한 항목은 이름·번호·생성기 버전을 보존하며 종전처럼 처음부터 재생합니다. 새 저장 형식은 이전 저장소를 백업으로 남겨 둡니다. 저장곡을 불러온 뒤 새로고침해도 선택한 구절을 복원합니다. 재생을 정지한 직후에는 마지막으로 듣던 구절을 저장할 수 있습니다.

볼륨·리버브 조절은 저장된 도입 악보를 유지합니다. 템포·밀도·악기 등 편곡 설정을 직접 바꾸면 다음 마디부터 새 설정으로 편곡하며, 새 흐름은 새로운 곡의 처음부터 시작합니다. 링크 공유는 기존과 같이 설정을 공유하며, 저장된 8마디 악보는 로컬 즐겨찾기에 보관됩니다.

헤더의 Kalavinka에 마우스를 올리거나 키보드 초점을 두면 가릉빈가로 바뀝니다.

헤더 오른쪽 KO/EN으로 화면 전체의 언어를 전환합니다. 매번 페이지를 열 때 브라우저의 기본 언어가 한국어이면 한국어, 그 외에는 영어로 시작합니다. 언어 전환은 재생과 음악 설정을 유지합니다. 조절 헤더의 기본값 버튼은 현재 분위기·리듬에 맞춰 여섯 슬라이더를 복원하며, 악기·음소거·시드·타이머는 유지합니다.

설정과 저장한 흐름은 브라우저의 로컬 저장소에만 보관됩니다. 음악 설정 변경은 다음 마디에 반영되고, 볼륨·리버브·음소거는 짧은 페이드로 적용됩니다. 집중 타이머는 재생을 시작할 때부터 시간을 셉니다. 재생 탭을 열어둔 상태로 다른 탭에서 작업할 수 있습니다.

## 설계

- **합주 v7:** v6의 화성·베이스·드럼을 유지하고 멜로디에 2마디 모티프와 8마디의 제시·응답·발전·마무리를 적용합니다. 동음 반복, 강세, 길이와 쉼표가 모티프의 정체성을 만듭니다. 짧은 비화성 이웃음은 다음 코드톤으로 순차 해결하며, 음의 릴리스도 해소 시점과 화성 경계에 맞춥니다.
- **장시간 전개:** 일반·D&B는 64마디, 앰비언트는 128마디마다 새 모티프를 도입합니다. 전환부는 이전 모티프를 인용하고 새 응답으로 이어집니다. 리듬 계열은 시드로 순서를 섞고 음형·강세 길이는 장마다 새로 정합니다. 변화 슬라이더는 구절 내부의 변주 폭과 빈도를 조절하며, 0에서도 긴 전개는 계속됩니다. 시간에 따라 상태를 쌓지 않아 다시 불러오거나 임의 마디를 조회해도 재현됩니다.
- **화성과 선율:** 분위기별 열 가지씩 총 30가지 코드 진행과 열두 조를 사용합니다. 마지막 마디는 일부 주기에서 다음 첫 화음으로 이어지는 코드로 변형합니다. 멜로디는 모티프 윤곽·음정 이동·베이스와의 충돌을 평가한 뒤 가까운 후보들 중 시드 기반 가중 선택을 합니다. 긴장과 해소는 음악적 휴리스틱이며 미적 품질의 보장은 아닙니다.
- **장르별 저음·리듬:** 여덟 베이스 리프 계열에 서로 다른 시작 위치·음정·길이·응답 마디를 둡니다. 앰비언트는 별도의 긴 음·쉼표 배치를 사용합니다. 전자 계열은 실제 킥을 피하는 베이스와 버스 덕킹을 사용합니다. D&B는 두 마디 드럼 반복 위에서 화음을 네 마디 유지하고, 느린 선율의 질문·응답과 구간별 브레이크를 연결합니다.
- **간헐적 필인:** 12가지 짧은 스네어·하이햇·림·탐 패턴을 구간 끝에 확률적으로 배치합니다. 킥과 기본 백비트를 보존하고, 도입·비움·앰비언트에서는 필인을 넣지 않습니다.
- **16종 음색:** 파트별 네 가지 합성음 중 선택합니다. 새 흐름에서는 네 파트 모두 직전과 다른 음색으로 바뀝니다. 직접 음색을 바꿀 때에는 악보와 다른 파트의 선택을 유지합니다. 음색·리듬 선택도 저장·공유합니다. 타격 악기의 연속 감쇠, 배음별 소멸 속도, 작은 어택 노이즈와 관악기의 호흡·비브라토를 적용합니다.
- **드럼 제작과 연주:** 네 킷의 하우스·D&B용 킥, 스네어, 닫힌·반열린·열린 하이햇, 림·탐을 직접 합성합니다. 세 강약과 두 타격 변형으로 총 336개 모노 버퍼를 처음 재생할 때 준비해 재사용합니다. 강약은 음색에도 작용하며 하이햇 초크, 반복되는 작은 타이밍 차이, 간헐적인 고스트 스네어를 사용합니다. 킥은 긴 리버브·딜레이에서 분리하고 다른 드럼은 짧은 공간을 공유합니다. 드럼 전용 EQ·완만한 포화·낮은 비율의 압축 후 전체 마스터링으로 보냅니다.
- **화면:** 큰 소개 영역과 반복 부제, 악기별 가짜 미터를 제거했습니다. 데스크탑은 한 화면에 조작부를 배치하며, 필요한 설명만 마우스·키보드·터치 도움말로 표시합니다. 중앙 파형은 실제 전체 출력을 보여줍니다. 가운데 정렬한 분위기 카드와 단정한 SVG, 7.5초 주기로 왼쪽으로 흐르는 배경 그리드를 사용합니다. 오른쪽 위 별하늘은 실제 출력의 저·중·고역에 따라 반응하며, 동작 줄이기 설정에서는 정지합니다.
- **백엔드 없음:** GitHub Pages에 정적 HTML·JS·CSS·폰트·오디오 클록 파일만 배포합니다.
- **런타임 API 없음:** 로그인, 데이터베이스, 모델 호출, 분석 추적, 외부 음원 다운로드가 없습니다.
- **독자 엔진:** 마디 단위 Score와 오디오 시계 기반 Transport를 직접 구현했습니다. Strudel 및 런타임 JavaScript 패키지를 사용하지 않습니다. 180ms 선행 예약, 마디 경계의 템포 변경, 지연 후 밀린 음 건너뛰기를 처리합니다.
- **Web Audio:** FM 건반, 패드, 저음, 노이즈 타악기를 직접 합성합니다. 잔향과 딜레이도 로컬에서 생성합니다. 리버브 0–100 슬라이더는 18ms 프리딜레이가 있는 잔향의 양을 실시간 조절하며 저장·공유됩니다.
- **실시간 마스터링:** 초저역 제거, 저중역·고역의 작은 EQ 보정, 완만한 버스 컴프레션, 피크 압축과 4배 오버샘플링 소프트 피크 곡선을 연결합니다. 피크 곡선은 Mastermind의 `applySoftKneeCurve` 방식을 재사용합니다. 볼륨 조절은 처리 뒤에 두어 압축 강도와 분리합니다. 무음 구간을 끌어올리는 자동 게인이나 외부 API는 사용하지 않습니다.
- **타이밍:** 정적 AudioWorklet 클록이 스케줄러를 깨우고, AudioContext 시간으로 미리 음을 예약합니다.
- **정지:** 소리를 페이드아웃하고 음원을 정리한 뒤 AudioContext를 suspend합니다.
- **재현:** 같은 생성기 버전·시드·설정으로 같은 음표·리듬·화음·타이밍 규칙을 재현합니다. 실제 출력은 브라우저 DSP와 샘플레이트에 따라 조금 다를 수 있습니다.

일반 실행은 새 편곡 규칙을 사용합니다. 기존에 저장한 음악과 공유 링크는 원래의 v1–v9 음표·리듬·코드 진행을 유지하면서 최신 드럼 음색과 믹스 처리를 사용합니다. 새 흐름·분위기·음색 선택부터 v10 편곡 규칙을 사용합니다.

제로 오버헤드는 서버 운영·API 요금·런타임 외부 의존성이 없다는 의미입니다. 브라우저 오디오 처리는 사용자의 CPU를 사용합니다. 기기 절전, 브라우저의 메모리 회수, 출력 장치 변경에 따른 중단 가능성은 남아 있습니다.

## 개발

Node.js 24 권장.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 빌드를 실행하고 Pages에 배포합니다. `base: './'` 설정으로 저장소 하위 경로에서 실행됩니다.

## 프로토타입 범위

세 가지 합성음 프로필, 네 기본 파트와 독립 아르페지오, 시드 생성, 설정 저장, 최대 12개의 즐겨찾기, 공유 링크, 25/50분 타이머, 집중 화면, 밝음·어두움·시스템 테마를 제공합니다.

현재 버전은 4/4, 장조·단조의 코드 진행 30가지, 파트별 네 가지 합성음 팔레트를 사용합니다. 보컬, 음원 파일 내보내기, 크롬 웹스토어 배포, 계정 간 동기화는 후속 범위입니다. 장시간 청취 품질과 여러 기기의 백그라운드 안정성은 계속 검토할 영역입니다.

마스터링은 연속 재생을 위한 경량 처리입니다. 파일 전체의 LUFS 분석·정규화나 인증된 트루 피크 리미팅을 제공하지 않습니다. 4배 오버샘플링은 소프트 피크 곡선의 앨리어싱을 줄이는 용도입니다.
